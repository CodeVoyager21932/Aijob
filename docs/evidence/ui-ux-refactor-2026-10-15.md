## 已交付的使用行为

### 共同界面与基础交互

- 主导航收敛为今日、找岗位、简历与经历、投递管理、日程。子页面通过任务内导航进入；原路由保留。1366px 下侧栏文字可见，编辑器默认折叠但仍有短标签和展开按钮。
- Career、Studio、Native 共用语义颜色、字号、按钮、输入和焦点状态。基础文件在 `apps/web/src/career-os/ui/tokens.css`、`controls.css`；页面文件负责布局，不再各自维护一套基础按钮样式。
- 快速打开支持任务别名、方向键和 Enter；对话框打开时不叠加全局快捷搜索。页内 query 变化不再由外壳重置焦点与滚动。
- 岗位标题与动作区分开排版；官方列表定位说明单独占行。方向图谱准备清单改到有效日程路由。
- 经历库增加明确多选、选中数量和组合入口；默认摘要、按需展开全文，低频操作收进更多菜单。

### 简历编辑、导入与模板

- 编辑器采用内容大纲、当前模块、实际 PDF 三个区域，空模块按需添加。模块及经历条目共用 `SortableList`，支持指针拖动、落点反馈、方向键、上下移动按钮和原有撤销。
- 表单只展开当前模块；条目可收起，项目名称独占一行。富文本工具栏紧凑显示，并反馈加粗、列表等当前状态。原有扩展字段、稳定条目 ID、来源关联和自动保存继续使用。
- `FileDropzone` 同时服务简历库和编辑器。支持拖放或点击 PDF/DOCX，保留 5 MiB 校验和进度；取消选文件不会预先创建空稿。已有原件仍可找回。
- 导入空态按内容高度呈现，原件存在后才展示历史与解析区。非空稿导入默认进入新稿，当前稿替换仍需用户显式选择。
- 模板候选使用当前保存正文在服务端生成真实 PDF。候选预览不写回正文，点击应用后才保存模板；应用栏固定在弹窗底部。四类主推改为清晰单栏、紧凑单栏、正文优先双栏、科研单页，旧模板继续可选。
- PDF 物理续行的处理进入现有导入器：仅在来源页、列、行距及字段关联等条件一致时合并续行，保留每个来源块的关联；文本和 DOCX 的段落边界不因此被一律抹平。没有批量重解析或改写旧稿。

### 单页产物

- 服务端输出先按当前版式排版，再最多两档收紧。保留正文、可见性、条目 ID 和来源，正文不低于 9.5 pt；收紧结果只用于输出，不回写正文。
- 页面常驻显示页数、更新状态和实际收紧字号。超页可定位相关条目，由用户精简或隐藏本次不用的内容；没有截掉第二页、自动删文或无限缩放。
- 下载先保存当前输入，再获取配对修订对应的产物。PDF 预览和下载共用文件；旧请求晚到或下载期间又有新输入，不允许旧文件冒充当前稿。
- 新生成的多页预览可以供整理查看，但正式下载返回单页溢出提示。历史保留文件不批量改写。
- DOCX 复用收紧后的布局参数，继续检查内容和链接完整、保持可编辑；本机没有运行 Word/WPS 实际分页检查，不能宣称任意办公软件都一页。投递单页文件以服务端 PDF 为准。
