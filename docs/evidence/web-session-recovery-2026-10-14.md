# 本机网页会话恢复交付

日期：2026-10-14。范围：现有 C 盘网页版；实施决定见 [ADR-0044](../decisions/0044-local-web-session-recovery.md)，操作见[运行手册](../runbooks/system-upgrade-local.md#网页访问与资料找回)。

## 结果

- 已记住原 Chrome 身份。30 天短期会话到期后续接相同 owner/epoch；不因到期另建空身份。同身份续接保留未保存草稿，不自动重放失败修改。
- “账户与资料”增加下载恢复文件及选择文件找回，不要求 SMTP 或另填 Key。重新生成会撤销旧文件。当前真实身份尚未生成恢复文件，留给 coco 在页面点击下载并妥善保存；没有把凭据写入聊天或仓库。
- 原 3 份简历的修订、正文、布局及标题，以及 AI/搜索加密配置与方向数量，实施前后摘要一致。没有复制材料、改密钥或迁移业务库。
- 原网页服务已重启并就绪，桌面专属工作保持暂停。

## 有限验证

- 既有 identity PG 集成文件：7 项通过（新增 4 个场景）。使用本次独立测试库和时钟推进，覆盖第 31 天续接及保存、无 Cookie 的恢复、原身份切换、文件轮换、用途隔离、Origin/CSRF、退出/撤销、epoch/删除和旧匿名到期。未改变业务会话的到期时间。
- API 客户端：20 项通过，含无前置 Cookie 恢复及同身份续接保留草稿。
- 资料页：5 项通过；沿用既有页面测试，补本机恢复入口与非本机邮箱路径。旧文案断言已随新行为调整。
- 受影响文件 lint，contracts/platform 构建（含类型）及 Web 构建通过。没有运行全仓大矩阵、AI/搜索调用或重做简历导出。
- Chrome 实看原资料页，显示“已记住此浏览器”、下载/选择文件入口及 3 份简历。真实用户的恢复文件生成与上传没有在浏览器代操作；凭据往返由隔离集成检查验证。

私有证据在 `.data/runs/web-access-20261014/`：`before.json`、`after.json`、`browser-access.png`。不含明文 API Key 或恢复凭据；不提交 Git。

## 使用限制

浏览器记住凭据最长闲置 400 天，使用时续期。清除浏览器数据或更换浏览器需要恢复文件；资料仍须存在于原本机数据库且保有原加密密钥。已删除或已过留存期的旧匿名身份不能找回。未扩展为公网账户系统或数据库灾备功能。
