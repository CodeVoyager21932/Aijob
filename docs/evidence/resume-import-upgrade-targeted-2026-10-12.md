## 首次失败与修正

两个 Typst 样本把日期区间的后半段换到了相邻 PDF 行。原先语义解析只在单个块内识别完整日期，因此一个样本的三个项目被合并，日期落入正文。

`native-cn-v9` 增加独立的相邻日期续行恢复：只接受同页、同栏、相邻行，前行以年月结束，后行只有区间连接符和结束日期（允许右括号）。不跨栏、不跨远距离段落，不越过显式纠错边界。原始提取块不改写，两个来源 ID 都进入绑定。

修复后只复用这两份已提取的块重跑语义解析：10 个日期检查全部通过；newspaper 项目从 1 个恢复为 3 个，sidebar 保持 3 个；来源覆盖均完整。其余六份没有重复解析。

首次审计脚本自身也有两处错误，均保留记录：用 JSON 字符串顺序比较文档导致七个存储往返假失败；最后一份文本 manifest 的 basics 被当数组。已改为结构比较并按 manifest 类型读取。前七份沿用首轮提取与解析结果复算检查，P09 单独补完。没有覆写首次输出。

本地原始与首轮结果在 `.data/system-upgrade-20261012/import-fields-first/`。其中 private 文件仅供本机复现，含原文，不进 Git；本文件与审计脚本只记录脱个人化期望、字段名和聚合结果。
