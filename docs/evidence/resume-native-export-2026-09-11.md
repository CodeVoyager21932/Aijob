# K1 增量：原生固定版本 PDF 下载

## 实现范围

- 新增前向迁移 066：原生正文/布局修订分支。沿用不可变修订表、owner/epoch、修订配对和现有权限；原生内容不伪装为旧通用正文。仅应用隔离测试库 55443，尚未应用业务库 55439。
- `checkpointNativeDraft` 在同一事务中锁定 owner 与文档、核对草稿版本、固定成对修订；相同内容复用当前配对。旧版本不覆盖，混配或跨账号读取拒绝。
- 导出产物服务抽出文档适配接口，复用已有幂等、租约、加密存储、删除及迟到结果处理。历史渲染保持原路径，原生走 React PDF。
- 原生渲染在一次性 Worker 中运行，同时最多 2 个、单次 60 秒、Worker 堆限制 512MB。本地字体核对哈希后加载，字体与图片不从外网读取。
- 下载按钮等待当前保存队列完成，再建立 checkpoint、生成产物、下载。生成期间的新编辑不会混入已固定版本。再次下载读取同一份存储字节。

## 验证结果

- 原生 PostgreSQL 7 项通过：Web API 角色、不可变修订、真实 PDF、重复下载、幂等、旧版本稳定、错误配对、跨 owner、并发、删除等。
- 历史导出产物 7 项通过：兼容渲染、删除后迟到结果、失败重试、租约替换、跨账号与采集角色无权限。
- Chrome 全链路通过：新建、多模块编辑、保存、撤销/重做、503 重试、360px、返回前刷新保存、刚输入即下载、再次下载字节一致。
- 对实际浏览器下载文件使用 pypdf 读回：1 页，最新输入、两个项目、期刊、技能与数字无缺项；Poppler 图片已查看，无正文截断或重叠。
- 数据库/平台/Web 类型检查、Web 构建与本轮新文件 Biome 通过。Web 仍有大分包警告，未声称性能收口完成。
- 首次浏览器启动赶在测试 API ready 前，出现代理 HTTP 500；等待 API ready 后完整复跑通过。没有将该启动失败描述成成功。

实际合成下载：`.data/resume-native-k0-20260911/output/native-browser-export.pdf`；重复下载 `native-browser-export-repeat.pdf`。测试工具 `tools/resume-native/browser-check.py`。不得将合成测试库或文件当作真实用户资料迁移结果。
