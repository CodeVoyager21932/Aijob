## 使用顺序

1. 研究者核对确认记录、代码版本和 5 个样本 ID，完成含真实样本的详情、返回恢复与官方外链走查。
2. coco 协调 2 名符合招募条件的朋友；两名校准用户不得计入后续正式 6 人。
3. 两名朋友分别使用同一原型版本和已确认岗位集合完成一次完整协议校准，记录搜索、筛选、详情、返回恢复、零结果、未知字段理解和主持人提示。
4. 研究者根据两次校准记录修订任务措辞、术语题、计时点、外链返回和记录方式；发生实质修改时，重做受影响的校准部分。
5. 将人工岗位池从 `5/20-30` 扩至 20–30 条；只有 coco 或指定复核者确认过的岗位才能更新计数，合成测试数据和未确认自动候选本身不计数。
6. 满足 G0 全部条件后，基于原始证据选择“进入正式实验 / 继续校准 / 修改人群”，不能以这些准备文件、岗位数量或页面可用性代替真人证据。
