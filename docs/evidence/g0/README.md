# G0 协议校准准备与状态包

本目录保存 2026-07-22 G0 决策前的实验准备、完成状态确认与后续去标识化记录。coco 已确认“协议已校准”，但该状态确认不代表两名合格用户已完成校准、协议可用或任何 Gate 已通过。

当前产品状态仍为 **Phase 0 / E0**。`codex/g0-research-prototype` 只是工程分支名称，不表示 G0 已通过。首批 5 条已由 coco 确认进入本地研究样本，因此人工岗位进度为 `5/20-30`；协议校准的可核验记录仍为 `0/2`，实际参与人次与逐场记录待确认；正式实验、稳定来源和 72 小时回访仍分别为 `0/6`、`0/1` 和 `0/6`。

## 使用顺序

1. 先读[协议校准完成状态确认](protocol-calibration-confirmation-2026-07-18.md)，只把它解释为 coco 的完成状态确认，不推断参与人数、任务表现或协议可用性。
2. 先确认实际参与人次；按同一去标识化结构归档已完成场次，不足两场则补做。每场覆盖招募条件、搜索/筛选/详情/返回恢复、零结果、未知字段、主持人提示、术语错误、近期行为基线、反例和守护事件。
3. 对每个可确认场次记录代码、5 个样本 ID、记录表和协议版本，并说明是否实质修改任务、术语、界面或记录方式；发生实质修改时，重做受影响部分。
4. 确认 6 名与校准用户不重叠的正式实验合格用户和 72 小时回访路径。
5. 将人工岗位池从 `5/20-30` 扩至 20–30 条；只有 coco 或指定复核者确认过的岗位才能更新计数，合成测试数据和未确认自动候选本身不计数。
6. 满足 G0 全部条件后，基于原始证据选择“进入正式实验 / 继续校准 / 修改人群”，不能以完成计数、准备文件、岗位数量或页面可用性代替真人证据。
