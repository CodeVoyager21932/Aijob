## 使用顺序

1. coco 先协调 2 名符合招募条件的朋友和 1 名指定人工复核者；两名校准用户不得计入后续正式 6 人。
2. 复核者逐条打开首批 5 条岗位的官方页面，按工作包核对主体、活动状态、职能范围、六个资格重点字段、职责与要求。
3. coco 或指定复核者明确确认岗位核验结果后，研究者才能把确认过的行手工装入研究目录；当前目录为空，`pending_review` 候选不得进入。
4. 两名朋友分别使用同一原型版本和已确认岗位集合完成一次完整协议校准，记录搜索、筛选、详情、返回恢复、零结果、未知字段理解和主持人提示。
5. 研究者根据两次校准记录修订任务措辞、术语题、计时点、外链返回和记录方式；发生实质修改时，重做受影响的校准部分。
6. 只有 coco 或指定复核者确认过的岗位才能转入正式人工样本并更新路线面板计数；原型代码、合成测试数据和自动候选本身均不计数。
7. 满足 G0 全部条件后，基于原始证据选择“进入正式实验 / 继续校准 / 修改人群”，不能以这些准备文件或页面可用性代替真人证据。
