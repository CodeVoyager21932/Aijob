## 1. 完成范围

- 建立仅作用于正式产品的“向阳生长 / Sunlit Momentum”设计系统，研究页与内部预览不继承。
- 重塑岗位列表与岗位详情的信息架构：中文编辑式首屏、证据优先、方向快捷筛选、配额旁注、单列比较、100→113 明确加载、官方申请交接。

- 使用 token、语义 DOM 和 Grid/Flex 重排保留未来手机端能力；本轮不做手机端专属交互。
