# R2 `jobs` 高保真切片实施记录

> 日期：2026-07-29  
> 状态：首个页面切片完成，已推广至全部正式页面并完成 R2 收口  
> 产品证据：仍为 `E0`，本记录仅证明工程与视觉实现

## 1. 实施范围

- 将正式产品包裹在独立 `.product-app` 作用域中，研究页与内部预览不继承 R2 token。
- 建立米白画布、墨色正文、群青主路径、杏黄提气、竹青确认和朱橙人味的首版设计 token。
- 更新正式产品品牌标记、中文副标、导航当前态、证据说明带、四步旅程和页面回顶行为。
- 将 `/jobs` 首屏改为“向阳生长”非对称构图，以“看清条件—核对证据—自己决定”解释产品，而不是展示匹配分。
- 增加常看方向快捷筛选、已应用条件数、配额旁注和直接浏览结果的短路径。
- 将两列同构岗位卡改为单列编辑式比较单元，横向并列企业、标题、城市/出勤/时长/薪资、来源、核验时间和详情行动。
- 把 API 已存在但页面未使用的 `nextCursor` 接入明确的“继续加载岗位”动作；首批 100 条可以继续加载至当前完整的 113 条。
- 将岗位详情进一步改为中文纸面标题、四列条件核对、双栏官方原文、来源证据区和高对比官方投递交接。
- 将同一标题、色彩、面板和状态语言推广到简历、推荐、洞察、对照修改与数据控制；没有改变这些页面的业务动作。

没有修改公共 API、数据库、契约类型、匹配规则、配额算法、来源状态或 AI 边界。

## 2. 浏览器验收

真实本地服务在 1280 × 720、DPR 1.5 下验收：

- `/jobs` 首屏、筛选、结果列表均无整页横向溢出。
- “直接浏览岗位”将 `#job-results` 停在 sticky header 下方 116px，不遮挡结果标题。
- 快捷选择“产品”后显示“已应用 1 项”，当前返回 52 条，其中包含按既有契约保留的方向未知岗位。
- 清除方向后首批载入 100 条；点击“继续加载岗位”后变为 113 条，按钮消失。
- 岗位详情、简历、推荐、洞察和数据控制页均使用共享 R2 外壳，打开后回到页面顶部，无运行错误或 1280 横向溢出。
- 抽看推荐页确认共享编辑式岗位单元能承载三轴依据，不出现排名或匹配百分比。
- 没有创建简历优化任务；对照修改页只验证了不存在任务 ID 的安全错误状态。
- 真实 320px 内容视口下，顶部导航改为局部滚动、旅程缩为数字步骤、岗位首屏改为单列；页面主体没有整页横向溢出，标题、说明和两个核心动作均保留。
- 正式页面可见焦点使用杏黄高对比轮廓；跳到主要内容链接、语义标题、表单标签和状态区域继续存在。全局 `prefers-reduced-motion` 规则以 `!important` 关闭平滑滚动并将动画/过渡缩至 0.01ms。
- 简历确认不存在记录时显示安全失败说明；删除回执不存在或过期时显示明确错误并提供返回岗位首页，不泄露记录是否属于其他 owner。

## 4. R2 收口边界

R2 正式页面实施与终局工程门已完成。完整对照修改数据态没有为了视觉验收新建 AI 请求，也没有读取本机数据库或浏览器私有状态寻找任务 ID；现有双栏、逐段决定、最终预览和导出结构已纳入共享设计规则，并由既有服务端端到端测试覆盖业务闭环。后续自然产生真实优化任务时，可把 populated state 截图补进证据，但它不是重新打开 R2 或放宽隐私边界的理由。

R2 没有设计手机端专属导航、手势或底部 Tab；只保留未来手机端所需的 token、语义顺序、Grid/Flex 重排、局部滚动和 320px 结构安全能力。
