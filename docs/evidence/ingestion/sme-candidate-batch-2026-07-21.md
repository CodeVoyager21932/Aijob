# 中小企业候选批次 01：只读审批包（2026-07-21）

## 1. 结论

本批只完成 Exa 只读公开资料研究，没有调用招聘接口、打开登录态、登记可运行来源或写入岗位。建议 coco 将 5 家全部批准为“允许进入来源技术核验”，不等于批准采集、导入、公开发布或确认公司规模。

优先顺序：神策数据、帆软、小鹅通、观远数据、袋鼠云。前两家已有较强的官方实习供给与规模证据；后三家必须先确认当前岗位供给、稳定匿名结构和规模证据，任一失败就暂停或替换。

## 3. 统一准入条件

真实低频核验前，每家公司仍需逐项补齐：

1. 企业主体与招聘入口之间的官方关联。
2. `sourceKey`、可复用 `adapterKey` 和精确协议、主机、端口、路径、查询参数白名单。
3. 访问政策、robots/条款、重定向和合理请求预算。
4. 当前活动实习标签、稳定岗位 ID、职责、要求、城市和官方投递方式。
5. 官方或政府规模证据；没有时继续 `unknown`，不得阻止岗位进入其他已通过的本机复核流程。

任何登录、验证码、动态验证、访问限制、个人邮箱、个人微信、二维码-only 或无法核验表单都会停止该来源。失败或部分运行不得关闭已有岗位。

## 4. 与产品 Gate 的关系

- 本批是候选发现证据，不是来源准入、人工抽检、分类金标或用户价值证据。
