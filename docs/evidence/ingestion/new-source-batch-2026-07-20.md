# 新公司官方来源首批评估与低频探测记录（2026-07-20）

## 授权与边界

- coco 于 2026-07-20 明确要求正式启动新公司官方来源评估和低频采集。
- 首批评估字节跳动、阿里巴巴、京东；遇到登录、验证码、访问控制或政策不明即暂停。
- 后续评估百度、华为、小米；真实岗位请求保持单页、低频和本机 `local_mvp`，不公开发布。
- 未使用企业账号、Cookie、推荐码、验证码、代理或登录态。coco 随后明确批准受控浏览器只读复核；浏览器仅用于观察官方页面及其公开脚本、发现可复现接口契约，不用于批量采集，正式探测仍由标准 HTTP 适配器完成。

## 首批暂停来源

### 字节跳动

- 官方入口：`https://jobs.bytedance.com/campus/position`。
- 2026-07-21 受控浏览器复核确认页面可以匿名显示约 5640 个职位，首屏 10 条均明确标记为“实习”，列表卡片包含稳定详情 URL、职类、项目、城市、职位代码和职责。
- 列表使用 `/api/v1/search/job/posts`，筛选使用 `/api/v1/config/job/filters/3`，详情使用 `/api/v1/job/posts/{id}`；三者均带每次页面加载都会变化的 `_signature`。不带签名的匿名列表请求返回无关 HTML，而不是岗位 JSON。
- 没有逆向、生成或复制动态签名。coco 明确批准 ADR-0016 的人工浏览器辅助导入例外：只读取无需登录或验证码即可显示的可见 DOM，仓库不实现浏览器采集 Worker、自动翻页或自动详情遍历。
- 当前只允许明确标记为“实习”的岗位；正式校招全职和社会招聘不进入本轮 100–200 条实习集。

### 字节跳动：人工快照与离线导入结果

- 人工逐条打开首屏 10 个官方详情页，确认 10/10 为实习，覆盖产品、市场、数据、研发和运营；没有出现登录或验证码。
- Git 忽略快照不含 `_signature`、Cookie、登录态或浏览器状态；Schema 限制单批最多 10 条，并对来源页、详情 URL、岗位 ID、职位代码、实习类型和重复项失败关闭。
- 离线导入运行 `aa5c2271-a5b8-41ef-ab75-c61aa3028280` 的网络请求数为 0，发现 10 条、规范化 10 条、拒绝 0 条；任务 `bb9b2741-e74b-407c-9213-5a492215f0a9` 成功。
- 重复导入相同快照直接复用原任务，`createdRevisionCount=0`。首次物化新增 10 个岗位版本和 10 个 v4 要求集；第二次物化返回 61 个 eligible revisions、0 个新版本、0 个新要求集、0 个疑似重复对。
- 数据库核对确认 10/10 修订为 `import_mode=manual`、10/10 明确为实习、10/10 使用官方详情链接、10/10 有活动要求集；整库仍约 16 MB，列表 API 返回 `totalKnown=61`。

### 阿里巴巴

- 官方入口：`https://talent.alibaba.com/` 与 `/campus/position-list`。
- 首页响应建立匿名 `SESSION`/`XSRF-TOKEN`，并加载 Baxia 与登录脚本；岗位列表未在确定性 HTML 中提供。
- 结论：`paused`，不携带匿名会话或模拟客户端调用。

### 京东：浏览器复核后进入本地低频试点

- 官方入口：`https://campus.jd.com/`；职位页加载的官方静态 `umi.js` 明确给出公开岗位接口，而不是通过猜测接口或解析验证码链路得到。
- 项目接口 `GET /api/wx/position/getProjectList` 公开列出 `type=internship`，以及 `planId=45` 的 `JD YOUNG-实习生计划`、`planId=51` 的 `新锐之星实习生`。
- 列表契约为 `POST /api/wx/position/page?type=internship`，请求体固定为 `pageIndex`、`pageSize` 和五个空筛选数组；单次人工复核报告 100 条实习岗位。
- 列表已包含稳定 `publishId`/`reqId`、职位名、职类、职责、要求、城市、业务线、项目和发布时间，因此本批不额外请求岗位详情。
- 官方静态代码给出分享详情路由；浏览器人工打开 `https://campus.jd.com/api/wx/position/index?type=internship#/details?type=internship&id=5851`，可见完整岗位详情和“立即投递”。
- 页面虽加载验证码相关脚本，但上述公开列表和详情在无账号、无 Cookie、无验证码条件下可读；本实现不触碰登录、申请记录、验证码或个人中心接口。
- 未发现允许第三方长期复制和公开聚合的明确授权，因此来源仍为 `pending_review`，只能进入本机 `local_mvp`。

### 京东：实际探测与物化结果

- 适配器 `jd-campus-public-api@0.1.0` 只允许 `campus.jd.com:443` 的精确列表路径、`type` 查询参数和官方详情路径；预算为最多 1 页、1 个请求、10 条岗位、最小间隔 2 秒。
- coco 已批准的真实低频运行 `1832f7e8-331f-424b-a762-d65a11e7db91` 发送 1 个官方列表请求，发现 10 条、规范化 10 条、拒绝 0 条、错误 0 个，官方报告总数 100，完成状态为 `partial`。
- 重复探测直接复用任务 `24a27c69-9066-4352-bfee-8e563b04d42b` 和原运行，没有再次触网。
- 首次物化新增 10 个岗位版本和 10 个 v4 要求集；第二次物化返回 51 个 eligible revisions、0 个新版本、0 个新要求集、0 个疑似重复对。
- 数据库核对确认 10/10 京东岗位为活动状态、10/10 有活动要求集、10/10 使用登记的官方详情链接；数据库整库约 16 MB，列表 API 返回 `totalKnown=51`。

## 第二组评估

### 百度：进入本地低频试点

- 官方入口：`https://talent.baidu.com/jobs/list?recruitType=INTERN`。
- `robots.txt` 返回 404；没有发现允许第三方长期复制和公开聚合的明确授权，因此政策状态保持 `pending_review`。
- 页面无需登录，以 SSR HTML 内嵌 `window.__INITIAL_DATA__`；`listData.listDetailData` 提供稳定 UUID `jobId`/`postId`、职位名称、官方职类、职责、要求、地点、项目类型和发布时间。
- 2026-07-20 评估时官方页面报告 399 条实习岗位；首屏为 10 条。
- 官方详情路由由同一官方页面代码固定为 `/detail/:type/:id`；本地交接地址限定为 `https://talent.baidu.com/jobs/detail/INTERN/{jobId}`。
- 请求预算：最多 1 页、1 个网络请求、10 条岗位、最小间隔 2 秒；不使用搜索结果中的 `recommendCode`。

### 百度：实际探测与物化结果

- 首次以适配器 `0.1.0` 执行时，官方脚本在 `window.__INITIAL_DATA__` JSON 后仍有初始化语句；解析器按失败关闭原则返回 `BAIDU_INITIAL_DATA_INVALID_BOUNDARY`。运行 `7b1fcbcd-0844-4c63-82ad-0a006e8ac907` 写入 0 条岗位，没有放宽边界或手工补写数据。
- 修复后的适配器 `0.1.1` 使用字符串感知的平衡花括号提取 JSON，来源政策升级为 v2；对应离线夹具保留了 JSON 后续脚本语句作为回归样例。
- coco 已批准的真实低频运行 `cf967b11-69f7-4e1a-b038-1bee8af74c2d` 只发送 1 个官方列表请求，发现 10 条、规范化 10 条、拒绝 0 条、错误 0 个，完成状态为 `partial`，没有尝试翻页。
- 首次 `catalog:materialize` 为这 10 条修订创建 10 个岗位版本和 10 个 v4 要求集；目录由 31 条增至 41 条。
- 重复执行同一探测直接复用原运行记录，没有再次触网；重复物化返回 41 个 eligible revisions、0 个新岗位版本、0 个新要求集、0 个疑似重复对。
- 数据库核对确认：百度 10/10 岗位均有活动要求集，10/10 申请地址均位于 `https://talent.baidu.com/jobs/detail/INTERN/{UUID}`；列表 API 返回 `totalKnown=41`。

### 华为与小米

- 华为官方实习项目存在，但当前职位列表对只读页面返回 0 条，尚未建立可复核岗位列表契约。
- 小米新机会页岗位列表依赖客户端加载；旧校园列表包含 2018 年过期岗位并出现验证码提示，不能作为当前目录来源。
- 两者仍保持未接入，后续只有发现确定性公开数据目标后才创建配置。

## 发布与证据结论

- 技术可读不等于获准公开；百度与京东新增岗位只能进入本机 `local_mvp`。
- 阿里没有因“主流公司”身份获得例外，也没有写入占位岗位；字节只使用 coco 明确批准的人工可见 DOM 例外，未绕过动态签名。
- 当前本机目录为 61 条：腾讯 14、南开就业网·好未来 7、美团 10、百度 10、京东 10、字节 10；距离 100–200 条扩容目标仍差 39–139 条。
- 全量工程门通过 300 项测试、225 个文件 lint、全部 TypeScript 检查与生产构建；人工导入 PostgreSQL 集成和 1000 岗位单 PostgreSQL 容量回归继续通过。
- 本记录不构成 G2 通过、来源公开准入或产品价值证据。
