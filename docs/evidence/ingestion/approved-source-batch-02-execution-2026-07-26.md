# 审批包 02 执行记录：纯 SME 批次核验、首批导入、ADR-0021 配额压缩与千寻快照（2026-07-26）

## 1. 授权与边界

- coco 于 2026-07-26 批准[审批包 02](source-approval-batch-02-2026-07-26.md)（名单修订为纯 SME 版：硕方、鲸驰寰宇、神谷文化、红海云、鹏扶），同日选定方案 A（[ADR-0021](../../decisions/0021-compress-large-company-quota-and-publish-sme-gap.md)）并同意安排千寻智能/万境千寻人工浏览器快照批次；放弃窗口 ≤6 天的 5 家企业。
- 核验与探测只使用 GET 公开页面；未登录、未处理验证码、未使用 Cookie 会话、未逆向动态签名、未使用代理或隐藏浏览器指纹。
- 浏览器仅用于人工发现与主体核验（高校详情页、企业官网页脚 ICP、飞书 ATS 可见内容及其页面自身调用的公开接口）；生产探测使用标准 HTTP 适配器。
- 每家实际请求数远低于审批包预算（≤10/家）：核验阶段每张高校详情页 1 次浏览器读取 + 1 次服务端无 Cookie curl 复现；探测阶段硕方 5 请求、其余各 1 请求。
- 所有来源保持 `pending_review` 与 `accessPolicyAccepted=false`，岗位只进入本机 `local_mvp`；公开 `/v1/jobs` 仍为 0。

## 2. 核验结果与冻结的确定性契约

共享适配器 `university-employment-detail-html` 0.1.0（`apps/platform/src/sources/university-employment-adapter.ts`）冻结三种载体页面格式；四页均以服务端无 Cookie curl 复现证明无会话依赖，原始 HTML 均为服务端渲染与严格 UTF-8。

### 硕方（supvan-info-internships，南开 correcruit 格式）

- 载体：南开就业网实习信息栏目详情页，6 个连续 ID（116235–116240）同日（2026-07-06）发布的同企业实习；meta keywords 中的"实习信息"栏目标记为官方实习语义（岗位标题不带实习字样）。
- 字段：`div.zpxx` 标签值对（投递邮箱/投递网址/工作地域/职位类别/学历要求/招聘人数）+ `* 专业要求：`/`* 职位描述：` 小节；发布时间有、截止时间无。
- **主体核验**：`supvan.com.cn` 页脚以营业执照与京ICP备160003891号-1 标注发布主体北京硕方信息技术有限公司；页面明示的投递网址 `https://www.supvan.com/joinUs` 属关联主体硕方科技（北京）有限公司（页脚版权 + 京ICP备12039575号），作为原文明示的官方投递入口采纳（南开·好未来 Moka 列表页先例），仅作用户导航目标、采集进程不请求（其站点 robots.txt 为 `Disallow: /`）。
- **邮箱拒绝**：投递邮箱 `wangjianli@jtsupvan.com` 的域名 `jtsupvan.com` 无可达网站且无主体证据，不等于企业官方域名，按 ADR-0017 白名单拒绝；逐岗写 `COMPANY_EMAIL_DOMAIN_UNVERIFIED` 复核标记，投递方式仅保留 `official_url`。

### 鲸驰寰宇（jcquant-internships，港中深 jobview 格式）

## 4. ADR-0021 配额压缩实现与执行

- 新增迁移 `016_company_quota_selections`：`catalog.company_quota_selections` 派生表（published_job_id 主键、配额/供给/确定性排名/selected），由目录物化在同一事务内整表重写。
- 择优规则：ADR-0020 两条优先轨道（jobFamily 为 product/operations/engineering/data_ai 的 known 值）优先，组内按 `published_jobs.created_at` 与 id 稳定排序；无 `small/medium` 规模证据企业配额 10，有证据企业配额 30。
- 读取层：目录 `loadLocalRows`、洞察样本 SQL 均按 `selected` 过滤（推荐候选集来自目录搜索，自然继承；历史冻结运行不回溯）；`/v1/jobs` 搜索响应新增 `companyQuotaGaps` 公开缺口分母，目录页显示"X/供给 Y"。
- 执行结果：普渡 30→10、慧策 30→10（约 3000 人 large 证据）、帆软 18→10、腾讯 14→10，共压缩 52 条；被压缩供给保留全部不可变版本与缺口记录，不删除任何历史。
- 新增集成测试覆盖：无证据企业 12 供给压至 10 且优先轨道整体在前、medium 证据企业配额 30、搜索响应缺口断言。
