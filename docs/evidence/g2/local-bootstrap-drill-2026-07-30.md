# 本地空库恢复演练（2026-07-30）

## 结论

`pnpm local:bootstrap` 已成为单一恢复入口，并在一次性隔离数据库 `aijob_bootstrap_20260730` 上完成真实演练。命令能够按顺序执行基础设施检查、迁移、来源登记、人工快照导入、受控来源探测、目录物化与健康检查；任何必需快照缺失或来源探测失败都会 fail-closed。

本次演练**未完成到最终目录一致性检查**。两个零网络人工快照成功恢复后，第一个真实网络来源连续三次遇到 `ECONNRESET`，命令按设计停止，没有物化空目录或报告伪成功。因此恢复入口已实现，但 P7“从空库恢复到与现有目录一致”的终局门仍未通过。
