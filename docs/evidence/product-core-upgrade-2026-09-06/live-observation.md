# 真实来源访问观察

日期：2026-09-06。原始结构化记录见 [live-access-observation.json](live-access-observation.json)。

本轮通过项目安全传输层，仅对三个现有主机各读取一次 robots.txt，共 3 次请求，没有扩大配置、启用定时任务、导入岗位或提升公开资格。

| 主机 | 本次结果 | 可以得出的结论 |
|---|---|---|
| adaps-ph.zhiye.com | 成功读取，已保存内容散列；登记路径未被禁止 | robots 检查可通过；完整访问依据和准入仍待核对 |
| jobs.bytedance.com | 成功读取，已保存内容散列；登记路径未被禁止 | 不代表动态页面适配器已在真实站点跑通 |
| talent.baidu.com | HTTP 404，正确记录为文件缺失 | 不因缺失直接拒绝，也不自动批准公开 |

另用网页读取工具观察现有官方入口：[百度招聘](https://talent.baidu.com/jobs/list?recruitType=INTERN)返回可读招聘列表，当时页面显示 471 个岗位；此数是页面观察，不是入库或有效供给数量。字节校园入口读取超时，灵明光子入口被网页工具的安全检查拒绝；这些结果均不等于企业无法自动化。

普通 HTML、受控动态 DOM、分页中断、异常空表、429、恢复与重复刷新，已由专属 PostgreSQL 和真实 Chromium 的离线整链测试验证。它们证明共享采集能力，不能替代对某家真实网站的接入验收。

34 份配置的主体、入口、现有技术路径、时效信号和请求成本上限见 [source-inventory.md](source-inventory.md)。原有配置没有完整公开准入记录。首次接入耗时、真实计划刷新成功率、人工介入率、异常恢复时长和新鲜度的持续观察均为 **未测**，不能用夹具或此次 3 个 robots 请求填充成功率。后续由已批准来源的实际计划任务累计，失败必须计入分母。

robots 状态分类依据 [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html)，产品对 401/403、429 和临时故障采用更保守的暂停/退避策略；该协议不构成聚合授权。
