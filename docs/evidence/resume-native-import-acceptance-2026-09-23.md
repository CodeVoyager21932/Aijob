## 样本与方法

- 旧独立渲染合成语料取其 20 份开发集：7 单栏 PDF、5 双栏 PDF、6 DOCX、2 文本。旧语料中曾标为 holdout 的 10 份后来也用于检查和调规则，本次不再称作盲集。旧开发集的既有分项评估记录为 736 项、无低于 95% 的项目；这是开发回归，不是新验收。
- 另在 `.data/resume-native-import-acceptance-20260923/fresh-holdout/` 用 ReportLab、python-docx 和纯文本生成 10 份新合成样本：3 单栏 PDF、3 双栏 PDF、2 DOCX、2 文本。它们不是 Aijob 输出文件；预期字段和文件哈希在运行 Aijob 解析器前写入 `manifest.json`，`seal.json` 锁定清单哈希 `84494b06c6c98570c006df6e554ce74e508640c6226d0766820f45d4d81a8970`。样本仅含虚构资料，不进 Git。
- 新盲集只运行一次。评分脚本 `tools/resume-native/evaluate-fresh-import.mjs` 在运行前核验清单与各文件哈希，保存解析器构建文件哈希；结果独立写到 `.data/resume-native-import-acceptance-20260923/results/fresh-holdout-evaluation.json`。脚本拒绝对同一结果文件重复运行。
- 统计覆盖姓名、电话、邮箱、条目主字段以及标注的学历、日期、职位和正文依据；另计多识别条目和提取失败。此 10 份没有逐字段标注所有可能的输出，未标注字段的正确性不能由本轮分数证明。

## 边界与下一步

本轮是**由非 Aijob 渲染器制作的合成固定样本**，不是来自真实用户或多家在线简历产品的原件，因此不代表全市场准确率。之前的 billryan 中文 PDF 因缺少可读的中文字形映射，文字提取不支持；继续单独报告，不能从分母中无声剔除。

首次失败时确定的后续工作是：在开发集补充“律所、医院、机构等非公司后缀＋职位”的通用用例，修复字段拆分，并制作新的未见样本复验。H09 作为首次失败记录保留，不能修改后重算为通过。

## 开源中文 PDF 边界检查与页面链路续验

本轮又固定了 4 个仓库的 6 份公开示例 PDF：Typst 三种版式、kenyon LaTeX、kody1126 研究生简历和 forfrt 中文简历。原始文件及 `manifest.json`（固定提交、URL、SHA-256）只在忽略的 `.data/resume-native-public-specimens-20260923/`，获取和审计脚本分别为 `tools/resume-native/collect-public-import-specimens.py`、`tools/resume-native/audit-public-import-specimens.mjs`。这些是开源项目样稿，不是真实求职者提交；没有逐字段金标，**不能计算精确率或召回率**。

首次读取暴露两个可复现的结构问题：窄侧栏样张两栏实际空白带不足旧规则要求的 18pt，导致姓名与正文标题合并、教育模块缺失；另一份 LaTeX 的章节标题前有图标字形，标题识别失败。现已在 `import-blocks.ts` 中只对“独立联系侧栏＋正文至少两个完整章节标题”的窄间距布局增加分栏候选，在 `import-headings.ts` 中识别单个图标前缀与“认证证书”，解析标识改为 `native-cn-v8`。对应合成几何回归覆盖了分栏与普通单栏日期不误拆。

修复后结果：Typst 窄侧栏的教育模块从 0 变为 1 条；带图标标题的 LaTeX 样张从 50 个待整理块降为 22 个。6 份样张均无提取异常，5 份中文文字层可读但质量仍为 `partial`，其中仍有 5–22 个待整理块；forfrt 样张抽不出中文字（0 个汉字），质量为 `unstructured`，50 个块待整理。这里的“已映射”仅指文字得到存放位置，不表示字段或经历归属正确。原 PDF 无 ToUnicode 文字映射、扫描图像、混杂图标字体等不能通过增加章节词条解决；导入界面应继续暴露待整理内容并允许用户改正。

为防止宽松分栏误伤现有输出，按锁定的 40 套短稿 PDF 再回导一次，结果在 `.data/resume-native-import-acceptance-20260923/pdf-reimports-v8/results.json`：40/40、1320/1320 非空标量和条目数量检查通过，0 未映射块；不把这一回归当作新盲测或 120 组输出重验。`resume-core` 84 项测试、构建和改动文件 Biome lint 通过。

隔离测试库 `55443` 的浏览器链路另用合成 DOCX 完成“从导入入口创建稿件 → 自动识别 2 条教育和 3 条实习 → 编辑姓名 → 保存 → 下载 PDF”。测试 API 使用 `tools/resume-native/test-server.mts`（3002）、隔离 Web 5194，两个脚本通过本机 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright；测试会话与业务端口分开。`tools/resume-native/browser-import-smoke.mjs` 和忽略目录 `browser-smoke/` 保留复现记录；下载的两页 PDF 共 785 个可读字符，读回修改后的姓名及学校，网页无运行错误。视觉审阅可见第二页内容较少，说明这一信息量较大的样稿虽无正文丢失，分页观感仍不能据此认定合格。这条下载走查只覆盖合成 DOCX 与一个默认模板，不代表公开 PDF 的逐份界面纠错、所有 40 套模板的真实导入排版、真实用户材料、BYOK 或正式部署已验收。

同一隔离环境另将固定的 Typst 窄侧栏公开 PDF 通过实际上传入口导入：教育条目在编辑表单中可见，原件来源面板可打开，45 个提取块可逐项查看，浏览器没有运行错误。复现脚本与截图为 `tools/resume-native/browser-public-pdf-smoke.mjs` 和忽略目录 `browser-public-pdf/`。这只证明该样张的导入与来源查看可操作，**没有逐字段核对或认可其自动分类准确性**。
