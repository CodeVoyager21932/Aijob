# C 款职向、邮箱默认排版与局部调整

状态：C 默认排版、局部字段操作、撤销/重做、保存重开及实际单页 PDF 下载已完成本轮实测；原 11 稿完整保全。文字拖选未做本轮人工操作验收，最终视觉仍待 coco 查看。本文件不以工程检查代替实际使用认可。

## 本轮问题与范围

coco 实看上一轮 C 教育短材料后指出“教研与阅读活动助理”和邮箱被折断，不能接受。上一轮的短尾行口径未覆盖职向语义和邮箱完整性。本轮只修 C 款这两个字段，不新增模板，不扩展为正文任意选区样式编辑。

默认排版只重排断行与位置，不自动减字号、不删除或改写文字。局部字号仅在用户主动操作时变化。正式 PDF 继续严格一页；放不下时保留正文并阻止正式多页下载。已有资料与原有对照页保留。

## 实现与默认成品

- 职向默认优先保留完整行；需要换行时按用户原有分隔符划分语义组，仍不足时移到右侧宽页首。邮箱默认保持完整，窄栏不足时移到右侧宽页首。
- C 预览字段提供点击定位和可键盘聚焦的旁侧按钮；实现保留原有文本层，拖选保护仅经过定向检查，本轮未人工拖选验收。基础字段面板提供 A−、字号、A+、自动/单行/光标处换行、自动/左侧身份栏/右侧宽页首位置及恢复默认。作用范围明确为整个职向或邮箱。
- `fieldLayout` 与正文分开保存，使用原始 UTF-16 光标位置记录手动断行。修改原文时仅使手动断行失效，保留字号、位置和显式单行策略；拒绝空白分段及字符内部断行。
- 字段调整复用现有撤销、重做、自动保存和重开链路。实际行为验收状态见下节。
