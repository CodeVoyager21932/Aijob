# 中文简历补充检索线索

2026-09-11。下列项目来自本轮搜索，不与已经完成 API/固定提交/源码复核的 20 个重点项目混计。低 Star 或功能范围小不意味着无参考价值，但不据此推荐整套替换。

| 项目 | 研究位置 |
|---|---|
| [LChromium/chinese-resume-template](https://github.com/LChromium/chinese-resume-template) | 通用/技术/运营三份内容，继承 liweitianux；许可摘要拆分 LPPL 与 CC BY；需要避免同源重复计数 |
| [ascendho/CV](https://github.com/ascendho/CV) | 中文 ctexart 及模块命令；小型模板补充 |
| [RavenLite/CompactChineseLaTeXResume](https://github.com/RavenLite/CompactChineseLaTeXResume) | 紧凑中文单栏；小型模板补充 |
| [forfrt/cn_resume](https://github.com/forfrt/cn_resume) | 中文算法岗模板；捆绑字体需要另核对 |
| [JinBridger/chicv-cn](https://github.com/JinBridger/chicv-cn) | 基于 chicv 的中文 Typst；不算新编辑系统 |
| [cmyk-labs/SimpleCNResume-LaTeX-Template](https://github.com/cmyk-labs/SimpleCNResume-LaTeX-Template) | 中文条目与强调命令；保留为模板候选 |
| [liyupi/laoyujianli](https://github.com/liyupi/laoyujianli) | 国内在线产品介绍；不能把宣传仓库等同完整开源编辑器 |
| [StoneLL1/resume-builder](https://github.com/StoneLL1/resume-builder) | AI Skill/本地编辑工作流，范围与 Aijob 在线多用户产品不同 |
| [LittleDrunkWang/resume-builder-cn](https://github.com/LittleDrunkWang/resume-builder-cn) | 中文求职 Agent Skill；不是成熟模板/文档编辑引擎 |

检索词包含“中文 简历 模板 开源”“resume builder 中文”“中文校招 LaTeX Typst”“GitHub 简历制作器”“BOSS 简历 风格模板”“全民 简历 在线 模板”“学术 简历 Word 开源”，并交叉使用 [awesome-resume-for-chinese](https://github.com/dyweb/awesome-resume-for-chinese) 的上游链接。

优先使用作者仓库、官方产品页与用户提供截图。搜索中出现的同名聚合/SEO 网站、他人的非模板简历 PDF、无来源搬运和模板网盘打包没有作为主要证据。商业官网宣传的通过率、使用人数、模板数没有当作独立验证结果。
