# ADR-0004：自动化前先进行人工礼宾验证

- 状态：accepted
- 日期：2026-07-15
- 决策者：项目维护者
- 关联：产品发现与实验、MVP 路线

## 背景

当前对首要用户、最痛问题、推荐价值和隐私接受度的判断仍是假设。如果先开发大量采集器、搜索和 AI 能力，可能只证明系统可实现，却没有证明用户会因此完成更好的投递决策。

## 决定

编码自动化主链路前，先完成行为型用户研究和人工礼宾实验：人工整理少量官方岗位，为 5-8 名目标用户提供经人工复核的证据式推荐，并观察官方链接点击、自报投递、复用和失败原因。

## 后果

- 正向：用较低成本优先验证最大价值风险，减少错误方向的工程投入。
- 负向：自动化开发会后移，人工实验不能代表规模化运行质量。
- 后续：只有礼宾实验达到阶段门，才进入三来源数据可行性和工程纵向切片。

## 复审触发条件

获得等价或更强的真实行为证据，能够直接证明同一价值链成立时复审。
