# ADR-0002：只接入白名单中的官方公开来源

- 状态：accepted
- 日期：2026-07-15
- 决策者：项目维护者
- 关联：来源与采集设计、安全威胁模型、合规与公开上线门

## 背景

项目的差异化依赖岗位可信和可追溯。综合招聘平台、转载内容或用户任意提交 URL 会引入真假、授权、SSRF、访问控制和长期维护风险。

## 决定

采集器只访问管理员审核并登记的企业官方招聘网站、高校就业网站和企业公开招聘页面。来源使用域名白名单、最小采集频率和原始证据链；不绕过登录、验证码、访问控制或明确禁止的访问边界。

## 后果

- 正向：岗位来源可解释，网络访问面和内容授权风险更小。
- 负向：岗位覆盖增长较慢，每个来源需要准入和持续维护。
- 后续：先验证 3 个代表来源，再按数据质量和用户价值分批扩展。

## 复审触发条件

官方开放 API、企业授权数据合作或新的合规结论改变访问边界时复审。
