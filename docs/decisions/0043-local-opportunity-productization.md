# ADR-0043：本机产品化、搜索连接选择和来源接入

日期：2026-10-13。状态：已接受（coco 明确批准执行）。

实施时序补充（同日）：coco 要求先在现有网页开发版完善产品，安装包相关同步、构建、安装验证及业务资料迁入暂停，待终版确认后恢复。此决定调整实施顺序，不回退已经实现的搜索、来源或简历能力；桌面代码和候选保留，当前不承担与开发版同步交付的要求。

## 决定

采用 [本机升级计划](../plans/local-opportunity-productization-2026-10-13.md)。ADR-0042 已有简历与订阅链路继续保留；本决定补充以下边界。

- 搜索由用户选择仅已有来源、复用个人 AI 搜索或独立 Tavily；不强制两份 Key。具备 Chat Completions 不代表有搜索，能力必须按当前修订的真实工具和来源元数据验证。失败不自动改供应商。
- 新 `user_source_discovery` 属于 owner/epoch 任务，由 match-worker 执行。collector 无个人凭据权限。match 只能通过受限函数提交规范公开 URL 线索，不能安装、启用或准入来源。现有 ownerless Tavily 保持兼容，显式迁移成功后停止对应旧需求。
- 个人密钥按 owner 派生加密，复用 AI 只引用现有连接。私有缓存、预算、能力状态、任务结果绑定 owner/epoch 与配置修订；删除流程覆盖新增个人数据。仅公共规范 URL 线索可全局去重。
- 维护者提供版本化来源目录；普通用户只选择可用范围。北森租户识别和有界实际试采复用现有安装/审核链。目录存在不等于已可采，试采成功不等于已获准公开。首次启用、扩大范围和恢复暂停仍需明确操作。
- Windows 11 x64 使用 Electron 薄壳、独立 Node/PG/Chromium 和现有三服务。安装数据与开发工作区隔离；当前用户 NSIS 安装，无强制管理员或 Docker。数据、密钥与身份跨升级保留。
- 本机设备凭据仅由桌面主进程持有，DPAPI 保护；数据库存哈希，受限 IPC 恢复现有 owner 会话。删除、撤销、epoch 变更后不能恢复。不新增公共 ownerId 登录入口。
- 无待迁移时不重复备份；退出只停止自身进程，启动失败不清空旧库；开机启动默认关闭。安装签名及公网发行独立报告。

## 保留

PostgreSQL 唯一查询/队列真源、三服务权限、访问范围、人工首次来源启用、官方事实、unknown 保留、用户自行投递、原件长期保留、稳定条目和投递快照均不变。不引入通用 Agent/第二套队列/新 PDF 引擎。

## 验证

按计划实施定向 PG、适配器/来源夹具、两条用户旅程与真实连接/计划刷新。禁止用模型自称、搜索摘要、HTTP 200、空占位选择器或未实际运行的任务冒充可用。真实外部条件未验时分别报告。
