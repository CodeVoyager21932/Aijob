# ADR-0044：本机网页自动续接与恢复文件

- 状态：接受
- 日期：2026-10-14
- 依据：coco 要求解决会话到期后只能人工找回的问题，仅修改现有网页版，保留数据和密钥。
- 补充 ADR-0005、0038；不改变 owner 保留、删除及服务权限边界。

## 决定

保留 30 天短期会话，另用 HttpOnly、SameSite=Strict 的浏览器凭据记住原身份。凭据最长闲置 400 天，使用时至多每天续期一次；短期会话到期后重新签发同 owner/epoch 的会话，不创建替代 owner。已有有效会话首次访问新版自动接入，无需重填配置。

在“账户与资料”提供下载恢复文件及选择文件找回。恢复文件是独立的随机 256 位访问凭据，不含材料或 API Key，用户妥善保存后可在同一本机服务的其他浏览器找回。文件在主动重新生成或 owner 失效前有效；重新生成使旧文件失效。恢复仅切换浏览器访问，不合并、复制或删除另一身份的资料。

复用 `identity.device_bindings`，哈希分别以 `web-browser-v1:`、`web-recovery-v1:` 区分用途，与桌面既有凭据互不接受；不新增表或迁移。自动恢复与文件恢复均核对 owner 活动状态、epoch、凭据撤销状态；旧匿名身份的留存期限仍有效，不复活过期或已删除对象。所有个人数据删除仍由原流程清除绑定。

文件生成需要当前会话、Origin 和 CSRF；恢复凭文件认证并检查 Origin，不自动建立新 owner。失败不切换身份。退出会话撤销该浏览器的记住凭据；全量会话撤销同时撤销网页记住凭据。恢复文件可继续用于主动登录，直到重新生成或资料删除。

前端遇到同一 owner 的短期会话续接时保留草稿；仍不自动重放失败修改。显式恢复会清除旧身份缓存并重新打开资料页。

## 范围与代价

仅 `APP_ENV=local`、回环监听且非桌面子进程时启用；Alpha/公网身份流程和桌面 IPC 保持原路径。普通用户不需要部署邮箱服务。

长期浏览器访问适合当前个人电脑用法。清除浏览器数据或超过凭据闲置期限后需要恢复文件；如果所有访问凭据都丢失，不能仅凭 owner ID 自动认领。恢复文件不代替数据库和原加密密钥备份，不能用于恢复已经删除的数据。公网、多用户共用电脑或设备管理需求出现时另行评审，不在本轮扩大账户系统。
