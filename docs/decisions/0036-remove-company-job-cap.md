# ADR-0036：取消单家公司岗位数量上限

- 状态：accepted
- 日期：2026-09-05
- 决策者：coco
- 依据：本轮明确要求「单家公司上限不必限制在30条，有些公司就是招聘大户」。
- 替代：ADR-0035 第五节的单家30条上限，以及 ADR-0021 的30/10分档；其他准入条件不变。

## 决定

单家公司不设岗位数量上限。真实岗位按逐条事实、资格、活动状态和来源准入判断，不因公司规模、同公司已有岗位数量或职能分布而截断。批次容量预估使用已核验供给数量，不取与30的最小值。数量集中度可如实观察，不自动产生新的隐藏规则或排序惩罚。

分页、网络请求预算、限速和安全边界仍是运行约束，不作为公司岗位总量上限。取消上限不意味着未准入来源可以公开，也不意味着重复、关闭或不合格岗位可以收入。

## 实施与兼容

取消目录、Case创建与升级、匹配状态、洞察及统计中的旧配额过滤；旧数据库 selected=false 不再决定可见性。保留历史表结构以兼容旧迁移，物化时全部选中，quota 字段只承载该次公司供给数。批次输出 quota=null 明示无上限；不再展示配额缺口提示。无需修改不可变岗位历史或真实业务数据库。

验证覆盖单家35条全部可检索、旧false投影不隐藏、关闭岗位仍撤下，以及85条容量不截断。验证结果以本轮执行记录为准。
