# ADR-0001：核心领域能力由项目自行实现

- 状态：accepted
- 日期：2026-07-15
- 决策者：项目维护者
- 关联：产品定义、安全威胁模型

## 背景

公开招聘聚合、简历解析和岗位匹配领域存在许多小型开源项目，但其数据来源、访问方式、安全边界、代码质量和维护状态通常不能精准满足本项目要求。直接作为底座会把未知行为和错误领域假设带入核心链路。

## 决定

来源注册、岗位规范化、资格判断、证据匹配和推荐契约由本项目自行定义并实现。外部资料默认只用于知识参考；通用库必须经过依赖准入后，才能以隔离、可替换的方式承担非核心基础能力。

## 后果

- 正向：核心数据、规则和安全边界可控，不受垂直小项目架构限制。
- 负向：需要自行实现和维护领域逻辑，初期开发速度可能较慢。
- 后续：每个正式依赖记录必要性、维护、安全、许可证和退出方案。

## 复审触发条件

出现由可信组织长期维护、领域和安全边界高度吻合、且迁移成本显著低于自研的组件时复审；仍不得未经评估直接替换核心模型。
