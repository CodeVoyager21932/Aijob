# ADR-0042：机会发现与简历准备统一升级

状态：Accepted（2026-10-12，coco批准完整执行计划）。

当前任务更新为 docs/plans/system-upgrade-2026-10-12.md。本决定更新ADR-0041中固定旧简历底座的实施方向，但保留原生文档、完整经历、成对修订和历史投递兼容；不重新执行K0–K5或OS-7。

1. 保留模块化单体、现有工作区及PG任务真源。方向订阅连接共享发现、来源刷新、岗位事件与站内摘要。
2. 首版Tavily免费basic搜索只发现公开线索，20请求/日500/月、24小时共享、不启用超额计费。新来源复用原有首次准入及安装流程，不能由搜索自动提升为公开获准。
3. 导入恢复内容套系统模板，局部纠错保留用户修改与ID；不复刻任意上传版式。原件留存、直接编辑、无需逐句确认继续适用。
4. 服务端PDF产物是编辑预览和下载的共同成品；新排版通过只读适配接入RRv6/Forme，不替换本地正文schema。旧模板及历史成品保持兼容。
5. 先完成四类主推视觉结构。新引擎两轮针对性修复仍不满足核心内容/中文/分页要求时，保留现有引擎完成产品改进，不再叠第三引擎。
6. 个人事实与岗位要求分层，AI结果局部采用可撤销；不以JD补个人技能/数字，不创建另一套助手。
7. 验证限于已有代表材料、受影响代码与两条用户流程；发布、BYOK和真实搜索分别如实报告。旧大矩阵不自动重跑。

2026-10-12 入口调整：coco确认调整后，岗位发现顶部提供方向表单和真实运行状态。搜索Key与现有来源刷新开关通过既有loopback内部台的专用配置页操作，本机配置使用原密钥派生加密并每轮读取；保持三服务权限与逐来源准入边界，Web API不增加管理写权限。保存搜索连接不会自动启用来源刷新。
