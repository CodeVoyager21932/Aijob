# ADR-0037：产品主体与受控供给自动化

- 状态：accepted
- 日期：2026-09-06
- 决策依据：coco确认完整执行六阶段产品主体升级计划。

## 决定

面向本科、硕士、博士在校生，覆盖实习、校招、应届和管培。学历和院校条件作为个人资格核对信息，不再以这些字段全局排除岗位；明确要求多年非实习工作经验仍属于独立的非目标范围。否定、优先和替代条件不得当作硬性限制。公司无岗位上限，100家/1000岗及分布保持报告项。

来源采集支持HTTP、已有ATS和隔离浏览器渲染；浏览器归属collector-worker权限边界，页面和子请求均受网络白名单、预算和失败隔离保护。机器人协议缺失（404/410）、访问受限（401/403）、限流（429）、网络/服务器故障及明确禁止分开处理。文件缺失不等于准入通过；其他访问依据仍需完成。首次启用和扩大网络范围需明确操作，同范围正常刷新自动完成。测试/CI不访问真实招聘站；正式采集仅在显式配置的私有采集运行环境执行。

允许复用内部CLI服务建设仅限本机/受限内部访问的异常复核台，不开放公共管理后台。AI可辅助接入和岗位语义分析，必须保存依据、版本、用途和预算；普通刷新复用结果。AI不改写官方事实、提升访问权限或自动确认个人经历。配置与预算缺失时规则保底，不自动购买服务。

分类采用主职能与子岗位/领域/任务标签；系统解释与官方字段分开。洞察支持小样本事实、两种分母、未明确必要性、原句追溯；公共聚合与个人比较隔离。保留旧洞察和Case固定版本。

首轮完成机会/申请/材料主流程、方向图谱、个人准备、材料复用、PDF下载、实际投递版本、招聘计划和日程；OCR、企业直供、趋势预测、社区及语音面试后置。保持PostgreSQL和三个权限边界，不进行架构重写。

## 兼容与验证

新增前向迁移，旧岗位/要求集/Case版本不可变；资格当前投影与历史快照分别处理。新增个人资产必须纳入owner隔离和删除矩阵。采集完整轮次、异常空表、撤回缓存、SQL/TypeScript规则一致性、模型降级、PDF、日历与窄屏均需验证。

本ADR替代早期硕博/院校全局排除、robots缺失一律停止、生产采集禁止浏览器及内部UI一律禁止的相应条目；不取消来源准入、禁止绕过访问控制、用户自行投递和数据删除边界。
