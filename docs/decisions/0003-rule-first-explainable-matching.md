# ADR-0003：采用规则优先、证据驱动的可解释匹配

- 状态：accepted
- 日期：2026-07-15
- 决策者：项目维护者
- 关联：简历解析与可解释匹配设计

## 背景

毕业年份、学历、地点、到岗时间等资格条件可以确定性判断；让语言模型直接给出总分，容易遗漏硬冲突、编造经历并让用户无法核对理由。

## 决定

匹配顺序固定为：硬条件规则 -> 真实证据召回与覆盖 -> 固定模板解释；AI 默认关闭且只在证明增量后参与受控解释。三轴结果必须引用岗位要求 ID 和用户确认的事实或证据 ID；信息不足时输出未知。AI 不得修改来源状态、资格结果、用户经历或用户决定。

## 后果

- 正向：结果可核对、可回归测试，并能在 AI 不可用时降级。
- 负向：需要维护数据字典、规则、证据模型和金标评估集。
- 后续：用真实用户反馈校准排序，但不以黑盒分数替代资格和证据。

## 复审触发条件

规则无法表达的高频资格场景显著增加，或评估证明新的模型方法在不降低可解释性和安全性的前提下稳定改善结果时复审。
