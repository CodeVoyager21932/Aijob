# ADR-0016：允许本机人工浏览器辅助导入受控官方实习岗位

- 状态：accepted
- 日期：2026-07-21
- 决策者：coco
- 关联：[ADR-0010](0010-ingestion-network-policy.md)、[ADR-0015](0015-local-all-function-internship-expansion.md)、[MVP 路线](../06-mvp-roadmap.md)

## 背景

字节跳动校园招聘页面可以匿名显示岗位列表和详情，但列表、筛选和详情 JSON 接口均依赖每次页面访问都会变化的 `_signature`。不带签名的直接请求不能获得岗位 JSON。逆向、生成或复制动态签名不符合 Aijob 不绕过动态验证的边界；将 Playwright 或浏览器运行时接入生产采集 Worker 也超出当前 MVP。

coco 明确批准在本机使用“人工浏览器辅助导入”，以便在不绕过签名、不登录和不处理验证码的前提下，把人工可见的官方实习岗位作为本地 G2 候选。技术可见仍不等于获得长期复制或公开发布授权。

## 决定

1. 浏览器只由维护者按批次人工启动，用于打开官方列表和岗位详情、读取当次可见字段并生成结构化快照；仓库不实现自动翻页、自动点击、签名生成或浏览器采集 Worker。
2. 首轮每个快照最多包含同一官方列表页的 10 条岗位；每条岗位详情必须由人工打开官方详情页核对。
3. 当前 G2 仍只接收明确标记为“实习”的岗位，包括日常实习、ByteIntern 和技术实习项目。正式校招全职和社会招聘不进入本轮 100–200 条实习验收集。
4. 出现登录要求、验证码、访问控制、错误页或无法确认字段时立即停止；不提交账号、Cookie、验证码、代理、动态 `_signature` 或浏览器状态。
5. 快照只能写入 Git 忽略的 `.data/browser-imports/`，并由无网络能力的本机 CLI 读取。CLI 必须校验来源页、详情 URL、稳定岗位 ID、实习类型、数量上限和重复 ID，任一不符时整批拒绝。
6. 导入后的来源和岗位继续保持 `pending_review`、`publicationState=review` 和 `local_mvp`；公开 `/v1/jobs` 保持为空。
7. PostgreSQL 继续作为唯一任务和查询真源。人工导入也必须留下任务、运行、快照、字段证据、不可变修订和幂等键；重复导入相同快照不得生成新修订或新岗位版本。
8. 人工导入不证明来源持续性、公开准入或产品价值，不能提升 G3，也不能计为人工分类金标或参与者证据。

## 后果

### 正向

- 可以用低频、可审阅的方式补充无法由稳定匿名 API 获取的官方实习岗位。
- 不需要逆向动态签名，也不把浏览器运行时引入产品部署和 Worker 权限边界。
- 快照、字段证据和数据库修订仍可复现并接受人工抽检。

### 负向与成本

- 人工逐条打开详情耗时，无法承担高频更新和大规模持续采集。
- 页面改版会让快照生成流程失效；旧岗位不能据此自动关闭。
- 来源访问政策仍未明确允许第三方长期聚合，因此这些岗位只能用于本机验证。

## 复审触发条件

- 字节提供无需动态签名的公开接口、JSON-LD 或确定性 HTML。
- 单批需要超过 10 条、需要自动翻页或每周维护超过 2 小时。
- 准备把正式校招全职加入产品、部署浏览器采集器或公开展示岗位正文。
