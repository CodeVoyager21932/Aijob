# ADR-0039：方向图谱与模板工作室

状态：2026-09-09 coco 批准实施。替代旧方案中与本次图谱和编辑体验冲突的设计；ADR-0035–0038 的业务边界继续适用。

## 决定

- 按 R1–R5 实施方向入口、版本化语义、连续模块编辑、常驻纸张与 30 套模板；24 套专业、6 套适度创意。颜色变化不作为新模板。
- 新语义区分任务、知识方法、工具、产物、通用能力、申请条件与领域；使用完整语句确定否定、优先和任选条件。公共聚合不调用用户 API。
- 保留 v1 与历史岗位/Case；新结果、概念投影和缓存使用独立提取版本，不改写官方原句。
- 编辑使用完整经历、模块专用字段与统一稿件修订。直接导入、原件保留、独立简历和 BYOK 沿用，不增加确认关卡。
- 模板通过共享注册表及排版部件接入；预览与 PDF 使用同源字体和分页。DOCX 独立验证。模板、渲染及正文/布局版本共同固定投递内容。
- 编辑器采用连续表单与常驻纸张，桌面可调双栏；不足 900 CSS px 时编辑/预览切换。保留 V2 全站视觉。
- 新增数据只用前向迁移，旧记录通过读取适配保持兼容。保留当前未提交改动；不再次恢复业务库或执行 OS-7。

## 验收

每阶段记录 Contract、Database/Platform、Web、Integrated Gate、Evidence。模板以 30 × 3 份合成中文材料验证预览、PDF、DOCX。真实 AI、来源和部署状态单列，不把夹具当生产验收。

执行与证据：[R1–R5 执行记录](../evidence/direction-studio-upgrade-2026-09-09/README.md)。
