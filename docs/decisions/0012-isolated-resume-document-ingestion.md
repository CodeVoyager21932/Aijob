# ADR-0012：允许本地 MVP 隔离处理 PDF/DOCX 简历

- 状态：accepted
- 日期：2026-07-18
- 决策者：coco
- 修订：[ADR-0006](0006-modular-monolith-runtime-boundaries.md) 中“不支持文件上传”的 MVP 边界
- 关联：[PRD v0.2](../01-prd-v0.2.md)、安全威胁模型、系统架构

## 背景

PRD v0.1 只允许用户粘贴去标识化文本，以减少文件解析攻击面。coco 已重新定义完整 MVP：真实用户应能直接使用常见 PDF/DOCX 简历，同时保留粘贴文本作为失败回退。文件解析因此成为本地完整闭环的必需能力，但不能把原文件交给第三方模型，也不能让不可信文档跨越用户数据边界。

## 决定

1. `POST /v1/resume-analyses` 接受 PDF、DOCX 或纯文本，单次最大 5 MiB；不接受 `.doc`、图片、压缩包、宏文档、加密文件或其他格式。
2. `web-api` 同时校验扩展名、声明 MIME、魔数和最小内部结构。DOCX 还限制条目数量、解压后总大小和压缩比，并拒绝宏、外部关系和异常路径。
3. 原文件使用独立数据加密密钥执行 AES-GCM 应用层加密并暂存在 PostgreSQL。任务只保存 `owner_id`、记录 ID、输入哈希、到期时间和 `owner_epoch`，不复制正文。
4. `match-worker` 在无网络、有限 CPU/内存/时间、临时目录隔离的子进程中解析；不调用 Microsoft Office，不执行宏、脚本、外部链接或嵌入对象。子进程结束后立即清理临时文件和内存缓冲。
5. PDF 没有足够可提取文本时返回稳定的 `scanned_or_image_pdf` 状态，引导用户粘贴文本；MVP 不引入 OCR。
6. 解析结果先经过服务器端 PII 检测，再返回 owner 页面进行浏览器侧检查和用户确认。用户明确允许前，原文和原文件不得发送给 AI。
7. 原文件和原文在证据确认成功后立即删除；未确认、失败或中断时也在提交后 24 小时与 `owner_expires_at` 中较早时间到期。
8. 本地 MVP 的结构校验和隔离解析不宣称能够证明文件“绝对安全”。进入公开环境前必须重新评估恶意软件扫描、操作系统级沙箱和解析器补丁响应。

## 后果

- 正向：用户无需手动转换常见简历即可完成端到端流程。
- 正向：原文件仍受 owner、TTL、删除墓碑和迟到任务拒绝约束，不进入岗位快照 Bucket或模型输入。
- 负向：增加 PDF/DOCX 解析依赖、资源耗尽和恶意文档风险，需要专门金标与故障测试。
- 负向：扫描 PDF 仍需用户粘贴文本，原版式不会保留。

## 验证门

- 有效 PDF、有效 DOCX 和纯文本可产生可确认候选。
- 伪造 MIME、超限文件、宏、加密 PDF、路径逃逸、ZIP bomb、超时和崩溃均被隔离并返回稳定错误。
- 解析日志、任务表、错误报告、临时目录和模型请求中不存在原文件或未获同意的正文副本。
- 证据确认、24 小时到期、主动删除和 `owner_epoch` 变化都能阻止旧任务恢复正文或写入结果。

## 复审触发条件

- 进入邀请制远程 Alpha 或公开服务。
- 增加 OCR、图片、复杂版式保留或新文件格式。
- 解析器出现高危漏洞或隔离边界无法在目标运行环境执行。
