# ADR-0032：以可达性取代 SME 作为供给结构门槛，并冻结五项收录属性

- 状态：proposed
- 日期：2026-08-28
- 决策者：coco
- 关联：ADR-0002、ADR-0010、ADR-0021、ADR-0025、ADR-0026、ADR-0027、ADR-0028、ADR-0029、ADR-0030
- 替代：替代 ADR-0027 及其后续修订中「SME 不少于企业数 50%、可见岗位数 40%」的结构门槛口径；不改写既有采集事实、岗位修订与历史证据

## 背景

Private Alpha 供给门槛用 SME 比例守「普通背景学生投得进」。2026-08-28 的复核发现该轴有三个独立问题。

**一、自我筛选偏差。** 同时满足「是 SME」和「有企业自控官方招聘页」的企业，本身已不是普通 SME。多数普通 SME 人员需求小、招聘体系不完善，只在综合平台招聘，而综合平台是硬边界禁止的。因此 SME 配额筛出的是偏样本，与目标相反。

**二、有时与目标反向。** 现有候选中半鞅私募基金、世纪前沿、宽德投资、鼎一投资等量化机构均为 SME 且有自有招聘域名，对普通本科生的可达性明显低于招商银行、宁波银行分行级校招（非 SME，同样有自有招聘域名）。SME 排序优先与 `SME_COMPANY_QUOTA=30 / NON_SME_COMPANY_QUOTA=10` 的现有实现会把最难进的机构排在最前。

**三、经验上从未接近。** 2026-08-03 容量审计实测 SME 企业 24.14%、SME 岗位 14.77%，目标为 50%/40%。在 29 家企业的分母下已相差一倍以上，且此后未改善。该门槛在当前来源结构下不可达。

同时，2026-08-28 的 A1 测量（n=345，本地开发库 `catalog.published_job_versions`）确认：`education_levels` 与 `majors` 的 `known` 数均为 0。根因不是数据缺失，而是 `apps/platform/src/sources/normalized-official-job.ts` 的 `structuredFields` 只包含 `arrivalTime`、`weeklyAttendanceDays`、`durationMonths`、`graduationYears`、`recruitmentBatch`、`publishedAt`、`deadline` 七项，不含学历与专业；`educationLevels` 在 `apps/platform/src/sources/**` 全目录零命中。因此可达性判定不能依赖结构化学历字段。

另一项 A1 结果影响活跃性口径：`deadline_at` 的 `known` 数为 80/345（23.2%）。明示截止日期覆盖不到四分之一，因此不能把「带明示截止日」当作活跃性守门的主要手段。

PostgreSQL 单一真源、模块化单体、确定性适配器、不可变修订、逐来源网络预算与失败隔离均继续适用。ADR-0029 关于「企业官网与官方 ATS 构成岗位目录唯一真源」的边界**不被本 ADR 改变**：高校就业网站、政府公共就业页面、企业公众号继续为 `discovery_only`。

## 决定

### 一、收录判据为五项属性，页面类型不再是独立判据

岗位可进入用户目录，必须同时满足：

| | 属性 | 判据 |
|---|---|---|
| P1 | 主体可证 | 能证明发布主体即实际雇主：ICP 备案归属、ATS 租户主体与企业一致、或企业域名招聘邮箱 |
| P2 | 内容第一方且完整 | 职责与任职要求为雇主撰写或投稿的原文，且完整到足以做投递决定；第三方改写、摘要、二次加工不算 |
| P3 | 投递直达雇主 | 官方 URL 或企业域名招聘邮箱（附页面原句）；第三方表单、问卷、二维码、短链、个人邮箱不算 |
| P4 | 活跃可核验 | 见第二条 |
| P5 | 可确定性解析刷新 | 结构稳定、可自动取值、可重复刷新 |

综合招聘平台与第三方聚合站由 P2 与 P3 自然排除，不再仅依赖名单。企业认证公众号由 P2（内容常为概述、要点不全）与 P5（无稳定结构、难以周期刷新）排除；若某公众号提供结构化接口并满足 P1–P5，可按本判据重新评估，无需修改本 ADR。

本条不放宽 ADR-0029：满足 P1–P5 仍必须同时满足 ADR-0029 第 1 条的来源归属要求。

### 二、`canonical` 来源必须为列表型，或岗位逐条带明示截止日期

按可探知关闭的能力分三层：

| 形态 | 能否探知已关闭 | 陈旧上限 |
|---|---|---|
| 岗位带明示截止日期 | 能，日期过期即失效 | 0 |
| 列表型来源（ATS 租户列表、官网招聘列表） | 能，从列表消失即视为关闭 | 一个刷新周期 |
| 冻结单条公告，无截止日期、不属任何列表 | **不能** | 无上限 |

目标是任何**用户可见**岗位的「已截止但仍显示」时长不超过 7 天。因此第三层**不得进入用户可见目录**：可探知性是 `eligible_for_alpha` 的必要条件，并由 `closure_detectable` 列显式暴露以供审计计数。

本机 `local_mvp` 内部预览**刻意不受**该条约束：它按约束定义是内部预览而非真实用户面，一并阻塞既无用户保护收益，又会让新来源在配好 absence policy 之前无法本机预览。Alpha 比 local 多一层要求，与 ADR-0029 既有模式一致。

本条是对 ADR-0029 第 6、9 条的加强，不是放宽。

### 三、以可达性取代 SME 作为结构门槛

1. 撤回「SME 不少于企业数 50%、可见岗位数 40%」。`organization.scale.band` 与 `scaleBand` 保留为观察字段，继续要求 `scaleEvidenceRef`，但不再作为门槛或排序主键。
2. 可达性判定 v1：对官方页面原文的职责与任职要求做**显式短语检出**，按以下优先级裁决。只读取页面已出现的字符串，不推断、不补写。
   - 命中 `985`、`211`、`双一流`、`重点院校`、`名校`、`QS` → `not_reachable_school_restricted`
   - 命中 `硕士`、`研究生`、`博士` 且未命中 `本科`、`学士` → `not_reachable_postgrad_only`
   - 命中 `本科`、`学士`、`学历不限`、`不限学历`、`专业不限`、`不限专业` → `reachable`
   - 其余 → `unknown`
3. `unknown` 不计入可达配额，也不用于补足门槛（沿用 ADR-0027 对 `conflict` / `unknown` 的既有规则）。
4. **门槛：可达岗位不少于可见岗位数 50%。** 依据为 A1 实测 58.8%，余量 8.8 个百分点；60% 为临界，70% 在不改进抽取的前提下不可达。
5. 配额轴替换：`isSmeScaleBand` → `isReachable`；`SME_COMPANY_QUOTA` / `NON_SME_COMPANY_QUOTA` → `REACHABLE_COMPANY_QUOTA=30` / `NON_REACHABLE_COMPANY_QUOTA=10`；排序键 `smeRank` → `reachableRank`。反霸榜语义不变：可达企业单家最多贡献 30 条可见岗位，非可达企业最多 10 条。
6. 不新增学校层次结构化字段。**正文未出现 `985` 等词不得推断为「不限校」**；该情形归入 `unknown`。
7. 若后续把学历抽取补入结构化字段并压缩 `unknown` 比例，可另立 ADR 上调阈值；本 ADR 不预设上调时点。

### 四、高校线维持 `discovery_only`，执行暂缓

高校就业网站转载的岗位在 P1–P3 上可能成立，但普遍不满足 P4（冻结单条、无截止日期）与 P5，且第三方系统性周期性收录其正文的许可问题未解决。本 ADR 不裁决其标准层面归属，维持 ADR-0029 第 2 条的 `discovery_only`。重启需同时满足：取得站点许可、且满足 P4 与 P5，并另立 ADR。

### 五、扩容主路径为 ATS 租户族与企业自有招聘页

与 ADR-0028 容量优先、ADR-0029「该缺口应通过更多官方 ATS 来源族和企业官网发现解决，不能降低证据标准补数」一致。ADR-0030 第 11 条的暂停条件（产品闭环通过）已满足，扩容已获授权。

## 后果

- 优点：结构门槛与「普通背景学生投得进」这一实际目标对齐，不再被大厂堆量满足；禁止规则从名单改为属性判定，更难绕过；假岗位有量化上限；可达性判定零契约改动、零适配器改动、零迁移即可落地。
- 代价：按 P1–P5 与 ADR-0029 归属要求，现有 34 个来源中仅 12 个（8 个 `organization_career_site` + 4 个 `official_ats`）为合格起点，22 个高校来源不计入。
- 风险：企业自控招聘页天然偏向大型企业与融资型科技创业公司，近期可达性比例可能仍偏低。该风险由第五条的主路径与配额上限对冲，不通过降低证据标准解决。
- 遗留：`unknown` 占 27.8% 偏高，指标区分力受限；开发库存在 `official-account-test`、`bytedance-manual-test`、`refresh-it-*` 等测试来源污染，需按 ADR-0029 第 4、10 条确认已被资格投影排除。

## 验证

- 可达性判定对给定岗位样本可确定性输出 `reachable` / `not_reachable_school_restricted` / `not_reachable_postgrad_only` / `unknown`，且 `unknown` 不被补写为任何具体值。
- `source:batch-plan` 与 `source:candidate-audit` 按可达性排序并报告可达比例；`scaleBand` 仅作观察输出，不参与门槛与排序。
- 无截止日期且非列表型的岗位 `closure_detectable = false` 且不能 `eligible_for_alpha`；列表型与带明示截止日期的岗位不受影响；`local_mvp` 与 `blocking_reasons` 不因该条改变。
- 资格投影、目录、匹配、推荐、洞察与供给统计继续使用同一集合，并有 PostgreSQL 集成验证。
- 测试来源与虚构企业在非测试目录中为 0。
- 公开 `/v1/jobs` 在独立公开准入通过前继续返回 0，这是正确行为。

## 复审触发条件

- 学历或专业进入结构化字段并使 `unknown` 比例显著下降。
- 高校线取得站点许可且满足 P4/P5。
- 访问政策判据（另见 ADR-0033）落地后，可达性分母发生实质变化。
