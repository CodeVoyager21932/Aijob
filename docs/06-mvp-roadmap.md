## 生效口径

- 供给单位为在校生可投岗位，覆盖实习、校招、应届和管培；依据显式条件排除不可投，unknown 保留，不推断补写。
- ADR-0035 已将 100 家/1000 岗、运营缓冲与人工占比改为报告项；城市、职能为观察指标，不能把规模愿望写成准入否决。报告项也不能被省略。
- 逐来源主体、访问政策、投递交接、活跃可核验、字段稳定等质量要求继续守门。robots 与 ToS 按 ADR-0033 核验；robots 允许不代表来源 approved。
- 本机 local_mvp 可以保留待审核事实；外部查询由逐岗位资格与双向 public_version_id 对账守门。缺少准入来源时公共目录为空是正确结果。
- 原句、硬性要求、优先条件分开；Case 固定岗位版本与要求集，只有用户明确确认才升级；投递列表不得冒充岗位直达页。

## 路线与下一目标

已完成工程基线 → OS-7 关闭 → SA Phase A / 首次取证 → 岗位事实纠偏与独立工作区验收 → **SA 准入证据核验与业务数据恢复准备**。

下一步按 [SA Track](plans/supply-admission-scaleup-track.md) 执行：先确认独立业务数据恢复点和运行环境，再核对已有 7 个 API 来源的 robots/ToS 缺口、同版本稳定观察和具体投递入口；逐来源完成准入，检查对账发布与撤回证据。40/70/100 为报告检查点，不为当前扩抓指令。

接续前先处理一个已确认的实现冲突：ADR-0035规定单家统一30条，而目录物化仍保留SME30/非SME10投影，现有测试仍证明旧行为。此项归SA接续修复，不在本轮岗位事实纠偏中宣称已解决；未修正前不得把旧配额压缩后的分母当作新口径完整供给。

本轮没有启动任何真实来源；既有来源刷新权限仍遵守 AGENTS 与 ADR-0026。首次启用、扩大请求范围、恢复暂停来源和浏览器快照需要人工明确操作。不得因本轮工程验收而自动打开定时采集、真实 AI、邮件、服务器或用户实验。
