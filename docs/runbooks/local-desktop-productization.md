# 冻结参考：Aijob Windows 安装候选与运行

> 当前暂停（2026-10-13）：按 coco 最新要求，安装包不再随开发版同步修改、构建或验收，资料迁入也暂缓；终版确认后再处理。本文保留为已有候选的运行参考，当前日常使用只按[网页版运行说明](system-upgrade-local.md)启动原网页开发版和 Docker PostgreSQL。下列安装、迁入与打包命令是候选原步骤，本次文档归一不执行它们。

适用 Windows 11 x64 本地候选，依据 ADR-0043。源码工作区仍是 `C:\Users\72998\Projects\Aijob`。本轮交付状态及限制见 [交付记录](../evidence/local-productization-2026-10-13.md)。

## 普通用户使用

1. 运行 `Aijob-Setup-0.2.0-x64.exe`，打开 Aijob。应用自带运行时，不需要自己安装 Node、PG、Docker 或 Chrome。首次启动会建立本机资料库；现有开发工作区的资料通过下方迁入功能转入，不会自动混入新库。
2. 在「发现机会」点击「设置求职方向」，例如产品实习、上海和杭州；保留每天 09:00 汇总。首次是当前机会，此后才计新增。
3. 「连接与运行」选择要持续刷新的已接官网并明确启用。当前提供先临三维、哈啰；城市与职能以官网实际岗位为准，未说明不会被当成满足条件。仅刷新已有官网不需要任何 Key。
4. 想扩展新招聘入口，再选择搜索方式：可检查并复用支持搜索的个人 AI，或使用 Tavily。HTTP 成功、AI 自称已联网或正文有链接均不代表搜索能力通过。检查失败可以继续只用已有官网，也可以主动改选 Tavily；系统不会暗中切换。
5. 写作 AI 单独按需配置地址、Key、模型；支持 OpenAI 兼容生成格式。协议/JSON/Token/超时在高级选项。Key 只填本机页面，不发到聊天；已保存 Key 无需重新填写。
6. 在「今日」看新增及变化，从岗位进入准备，导入或选择简历，手动编辑、下载、回官方页面自行投递，然后记录实际文件。无 AI 同样可以完成编辑和导出。

搜索与已有官网刷新是两项能力：搜索产生待核验的入口线索，不会直接变成岗位；维护者接入后，普通用户在批准范围内自动刷新，不需要逐家写配置。目前未覆盖的网站可能需要维护者补充适配。

## 运行、暂停与资料

- 安装资源与个人数据分离。默认数据在 `%LOCALAPPDATA%\Aijob`，包含独立 PG、加密配置、本机身份、保留文件、日志与备份；卸载保留数据。
- 关闭窗口进入托盘，后台继续处理；在托盘或设置选择「完全退出」才会停止后台及自有 PG。开机启动默认关闭，可在设置主动开启。
- 关机期间不执行任务；下次启动合并到期变化，不补放每个离线日。搜索达到额度只暂停新发现，已有官网继续刷新。
- 只用已接官网、暂停方向或暂停官网不会删除材料。已下载/投递的保留产物与原件不受临时预览缓存清理影响。
- 端口首次分配后固定；占用时显示错误，不自动换 origin 丢失会话。启动失败打开日志，原库不会被静默重建。连续 worker 启动失败最多恢复三次。

## 备份与迁入

设置中的「完整备份」会停止写入，导出 PG 与保留文件、配置和加密主密钥，然后重新打开。备份应整个文件夹保留；`aijob-backup.json` 记录数据库 SHA。密钥使用当前 Windows 账户的 DPAPI，当前支持同一 Windows 账户下恢复，不能当作跨账户通用明文备份。

「导入备份」恢复到新的资料目录，验证成功后才切换，当前资料目录保留。「迁入原工作区」选择含 `.env` 的原项目目录，界面显示仍有效账户的简历/方向数量；停止原 API、worker 后选择正确账户，原 PG 可以继续运行。向导先备份、复制原主密钥及保留文件，再恢复并绑定原账户。成功后原目录写入 `.data/desktop-migration.json` 防止两套调度同时运行；原 DB 和文件不删除。失败不切换、不复活已删除账户。

本次安装检查使用独立测试目录，**没有迁走 coco 当前业务库**。以后实际迁入前先确认原应用无任务运行。需回退时先完全退出安装版，确认不会重复刷新后再移走原目录的迁出标记。不要在两份库中同时继续编辑并假定它们会自动合并。

## 维护与复现

运行时固定版本及下载校验见 `apps/desktop/runtime-lock.json`。`apps/desktop/scripts/stage-runtime.mjs` 从当前构建产物组织只读资源、依赖及许可；`refresh-stage.mjs` 更新增量产物和逐文件 SHA；`pnpm --filter @aijob/desktop package` 生成 NSIS。Web 必须使用 `pnpm --filter @aijob/web build:desktop`；普通受限生产构建不等于桌面入口。

安装包不包含原 `.env`、业务库、简历原文、Key 或 `.data`。构建使用 `.data/desktop-bundle-20261013`，运行使用用户数据目录。`afterPack` 会按资源清单检查必需文件，依赖目录有独立打包映射；Git 目录占位文件不列为运行资源。新增迁移保持前向；当前业务已应用 072–078，升级前一次备份在 `.data/local-productization-20261013/business-upgrade`。

本轮为未签名的 Windows 本机候选，签名发行与自动升级另列。安装包位置及 SHA 以交付记录为准。

定向复现脚本位于 `apps/desktop/scripts`：`smoke-desktop.mjs`、`desktop-journeys.mjs`、`backup-smoke.mjs`、`legacy-smoke.mjs`。它们仅操作命名的隔离夹具目录，不把真实网站网络访问纳入测试；不要常规重复运行已通过旅程。新问题先定位受影响环节，再决定是否重跑。
