# R2 UI/UX 视觉参考与设计方向提案

> 【历史归档】本文记录 2026-07-29 的旧 `ProductShell` 视觉方向和当时验收，不提供当前 Career OS 任务。现行视觉目标以[前后端同步改进计划](../career-os-current-delivery-plan.md)和三张 Career OS 概念图契约为准。

> 状态：Completed / 2026-07-29 实施与终局工程门完成  
> 日期：2026-07-29  
> 范围：R2 桌面端 UI/UX 系统重塑；保留未来手机端能力，不改变产品、数据、来源或架构边界

## 1. 本轮修正

上一版过度强调可信、克制和信息效率，视觉情绪偏冷、偏静，缺少 coco 要求的青年活气、生长力与高级审美。

R2 不应只做“更整齐的后台”，也不应变成色彩很多但没有气质的年轻化模板。新的设计目标是：

> **向阳、洒脱、聪明、可信。**

这次修正再增加一个明确要求：Aijob 不能像“把欧美产品翻译成中文”，也不能靠红金、书法和传统纹样假装中国。它应首先是一款为中国学生设计、用中文思考的当代产品，再兼收国际产品设计的成熟方法。

用户打开 Aijob 时，应像走进一间阳光充足、充满行动感的青年工作室：

- 第一眼有精神、有方向，但不兴奋过度。
- 长时间阅读岗位与简历时安静、清楚、舒服。
- 关键行动有力量，未知和冲突不制造焦虑。
- 每一处颜色、图形和动效都有用途，不靠贴纸和装饰堆“年轻”。
- 即使没有插图与动画，排版、色彩和信息节奏本身也有审美完成度。

新的产品视觉隐喻是：

> **向阳青年职业刊 × 轻盈投递决策工作台 × 可信证据系统**

其中：

- “职业刊”负责好奇心、视野和编辑审美。
- “决策工作台”负责效率、比较和行动。
- “证据系统”负责来源、未知、边界与用户控制。

## 2. 重新检索后的视觉参考

本轮不再要求职业产品同时承担所有视觉参考。职业产品负责信息结构，优秀的创意工具、金融产品与生活方式产品负责气质和完成度。

### 2.1 Figma：可收可放的青年创造力

- 官方参考：[Figma 2024 视觉语言更新](https://www.figma.com/blog/figma-on-figma-evolving-our-visual-language/)
- 参考理由：Figma 将新视觉建立在多样基础图形、动态组合、扩展色板和动作原则上；它可以在严肃产品界面与充满生命力的品牌表达之间切换。
- 最适合 Aijob 借鉴：
  - 不是“少用颜色”，而是建立有规则、可切换强弱的颜色语言。
  - 简单图形经过组合即可有生命力，不需要复杂插画。
  - 需要绝对清楚的任务界面保持克制；入口、空状态和阶段完成可以更大胆。
  - 图形表现“正在生成、移动、连接和成长”，而不是展示完成后的完美人设。
- 不照搬：大面积极繁配色、黑色粗描边和设计工具特有的节点语言。

### 2.2 Wise：热情向上，同时保持可信

- 官方参考：[Wise 品牌更新](https://wise.com/gb/blog/a-brand-for-everywhere-wise-unveils-bold-new-look)
- 参考理由：用鲜明绿色、粗壮字体、全球符号和少量有冲击力的辅助色，把高度严肃的金融任务做得积极、有行动感。
- 最适合 Aijob 借鉴：
  - 主色拥有强识别度，而不是通用 SaaS 蓝紫渐变。
  - 大标题有挑战者精神，按钮和任务路径仍然简单。
  - 鲜艳辅助色只在需要提气的时刻出现。
  - “去往更远地方”的开放感适合职业探索语境。
- 不照搬：货币纹样、国别符号和过度商业化的转化文案。

### 2.3 Monzo：乐观、人性与有意图的亮色

- 官方参考：[Monzo 视觉品牌更新](https://monzo.com/blog/weve-had-a-little-makeover) / [Monzo 新网页设计系统](https://monzo.com/blog/reimagining-monzo-com-building-a-modular-high-fidelity-web-design-system-that-scales)
- 参考理由：以 Hot Coral 表达温暖和乐观，同时用深海军蓝、柔和白与功能字体维持金融产品可信度；最新版网页系统明确将珊瑚色限制在品牌性和愉悦时刻，避免与错误状态混淆。
- 最适合 Aijob 借鉴：
  - 亮色可以表达生命力，但必须与错误、冲突等语义状态分开。
  - 品牌展示字体可以热情，功能字体必须长时间易读。
  - 温暖摄影、戏剧性光影和少量夸张 UI 能提升人味。
  - 动画只在恰当时刻引导注意，不持续抢占视线。
- 不照搬：金融卡片造型、卡通人物与大面积珊瑚底。

### 2.4 Daylight：阳光、纸张和舒服的数字空间

- 官方参考：[Daylight Computer](https://daylightcomputer.com/)
- 参考理由：以暖纸白、低饱和材质、精致衬线标题和一束橙色阳光建立“更关心人的电脑”气质，页面宁静但不冷淡。
- 最适合 Aijob 借鉴：
  - 暖背景和自然光感能降低长时间求职阅读的疲劳。
  - 标题可以有文学性和呼吸感，正文仍保持现代无衬线。
  - 橙色像阳光一样偶尔照进页面，而不是成为所有按钮的底色。
  - “舒适”来自材质、节奏和字体，而不只来自大圆角。
- 不照搬：硬件产品的沉浸式长页面、超宽字距和低信息密度。

### 2.5 Cosmos：高级审美、自由探索与不喧闹

- 官方参考：[Cosmos](https://www.cosmos.so/) / [The Future of Cosmos](https://www.cosmos.so/blog/the-future-of-cosmos)
- 参考理由：以高品质字体、充足留白和策展式内容建立审美门槛，同时强调好奇心、来源和上下文，而不是用高刺激 Feed 争夺注意力。
- 最适合 Aijob 借鉴：
  - 岗位探索可以像策展，不必像无限信息流。
  - 高级感主要来自字体、比例、内容质量与节奏，而不是玻璃拟态和特效。
  - 让内容保留来源与上下文，和 Aijob 的证据原则一致。
  - 允许用户“闲逛和发现”，但始终能回到明确任务。
- 不照搬：以图片为主的瀑布流与过度轻量的功能密度。

### 2.6 Dropbox：大胆色彩也可以系统化

- 官方参考：[Dropbox 色彩规范](https://brand.dropbox.com/color) / [Dropbox 创造力品牌更新](https://blog.dropbox.com/topics/company/-dropbox-unveils-colorful-new-look-and-global-brand-campaign-foc)
- 参考理由：以 Coconut、Graphite 和 Dropbox Blue 作为稳定核心，再使用有明确规则的多组亮色创造意外组合与创作能量。
- 最适合 Aijob 借鉴：
  - 先有稳定核心色，再允许页面出现不同情绪色。
  - 色彩要引导焦点、强化身份，而不是平均铺满界面。
  - 内容区可以保持安静，入口与阶段页可以更具张力。
- 不照搬：高对比品牌广告拼贴和每个模块更换整套色板。

### 2.7 Pitch：高完成度、强标题和精确动效

- 官方参考：[Pitch](https://pitch.com/) / [Pitch for Design Teams](https://pitch.com/teams/design)
- 参考理由：用强标题、紫色与酸性浅绿、高质量产品截图和精确动画，建立“产品本身就是设计作品”的完成度。
- 最适合 Aijob 借鉴：
  - 首屏和阶段标题应有记忆点，而不是普通后台标题。
  - 产品界面截图、示意图和真实组件可以成为视觉主角。
  - 动效用于讲清任务关系与状态变化。
- 不照搬：180px 超大标题、营销页节奏和高频紫绿撞色。

## 3. 中国侧视觉参考：建立母语气质，不做中国元素贴皮

中国侧参考分为两层：

- **数字产品层**：负责中文排版、信息密度、交互语气和本土用户的舒适度。
- **文化气质层**：负责色彩、材质、留白和含蓄的东方审美，只点到为止。

### 3.1 OPPO Design / ColorOS：当代中国设计的感性与理性

- 官方参考：[OPPO Design Center](https://design-center.oppo.com/cn/product/detail/Find-X9-Pro) / [ColorOS Aquamorphic Design](https://www.oppo.com/en/newsroom/stories/introducing-aquamorphic-design-of-coloros13/)
- 参考理由：OPPO 的设计语言强调“熟悉亲切”“更恰当、更克制”“简约轻盈”，又用日出到日落的天空变化建立有温度的色彩和流动感，适合作为 Aijob “青年活力但不浮躁”的中国侧主参考。
- 最适合 Aijob 借鉴：
  - 感性与理性并存：品牌区有情绪，任务区有秩序。
  - 留白不是空，而是给内容、动作和下一步留出势能。
  - 用光、层次和细微位移制造“正在向前”，不靠持续动画。
  - 中文文案短、准、有人味，不翻译欧美增长话术。
- 不照搬：手机硬件的拟物材质、整页发布会叙事和高成本 3D 渲染。

### 3.2 HarmonyOS：杂志布局、艺术纹理与跨设备秩序

- 官方参考：[HarmonyOS 4](https://consumer.huawei.com/cn/harmonyos-4/)
- 参考理由：其“艺术布局”“个性留白”“杂志主题”说明中国消费级系统可以同时具有秩序、审美和个性；跨设备设计也契合 Aijob 先做桌面、保留手机端能力的要求。
- 最适合 Aijob 借鉴：
  - 中文大标题与信息模块之间有清楚的气口。
  - 页面可像杂志展开，但操作路径仍遵循系统化栅格。
  - 纹理和色块只承担章节与情绪，不覆盖真实内容。
  - 同一语义组件在不同宽度重排，而不是为桌面绝对定位。
- 不照搬：系统桌面卡片拼盘、拟物图标和大面积营销视频。

### 3.3 flomo 与不背单词：自然生长、低压力和专注一件事

- 官方参考：[flomo](https://flomoapp.com/) / [不背单词](https://bbdc.cn/)
- 参考理由：flomo 用“持续记录，意义自然浮现”表达成长，不制造升级焦虑；不背单词把复杂学习任务拆成清楚、干净、可持续的单次行动。二者都比常见“青年成长平台”更克制、更尊重用户。
- 最适合 Aijob 借鉴：
  - 把成长表现为事实和证据逐渐累积，而不是战力值上升。
  - 一屏聚焦一个核心决定，辅助信息按需展开。
  - 中文提示语轻、短、自然，不命令、不打鸡血。
  - 卡片可以有温度，但不把所有内容装进同一种白色圆角容器。
- 不照搬：笔记流和单词学习的单任务模型；Aijob 仍需支持比较、核对与多阶段决策。

### 3.4 少数派与 TOPYS：中文编辑节奏、观点感和青年文化视野

- 官方参考：[少数派](https://sspai.com/) / [TOPYS](https://www.topys.cn/) / [TOPYS 关于我们](https://www.topys.cn/about)
- 参考理由：少数派善于在高中文信息密度中建立明确阅读顺序，并用单一强调色维持节奏；TOPYS 把全球创意视野和本地中文表达并置，页面有文化感但不故作高深。
- 最适合 Aijob 借鉴：
  - 标题、导语、正文、来源和旁注形成编辑层级。
  - 高密度信息区保持紧凑，章节之间再释放大留白。
  - 允许有态度的短标题，但事实正文保持中性准确。
  - 岗位详情用“边注/眉批”安放来源、未知、日期和核对提示。
- 不照搬：内容媒体的信息流、深色阅读主题和依赖封面图制造活力。

### 3.5 小宇宙与潮汐：青年人味、自然呼吸与不过度解释

- 官方参考：[小宇宙](https://www.xiaoyuzhoufm.com/) / [潮汐](https://tide.fm/zh_CN/)
- 参考理由：小宇宙的中文产品语气亲切、有社群温度；潮汐用自然、节律与安静空间降低心理负担。二者适合校准 Aijob 的人味和舒适度，而不是承担复杂工作台结构。
- 最适合 Aijob 借鉴：
  - 允许用户先感到被理解，再进入复杂核对任务。
  - 空状态与引导文案可以温暖、略带轻松感。
  - 长阅读页保留自然呼吸，不用密集分割线切碎注意力。
- 不照搬：播客社区身份、冥想氛围和过低的信息密度。

### 3.6 观夏、蕉内与 NIO Life：东方材质、青年态度和设计驱动

- 参考：[观夏的东方文化表达](https://www.jiemian.com/article/7660346.html) / [蕉内](https://www.bananain.com/) / [NIO 品牌与 NIO Life](https://www.nio.com/about)
- 参考理由：这组不是交互模板，而是文化气质校准。观夏把季节、气味和中国记忆转成当代表达；蕉内用简洁系统和鲜明态度重做日常基本款；NIO 以天空、地平线、行动和共同成长表达积极未来。
- 最适合 Aijob 借鉴：
  - 中国感来自当代生活经验、材质和语气，不来自古风符号。
  - 用米白、墨色、群青、竹青、朱橙构成现代东方色盘。
  - 品牌图形可以表达光、地平线、展开与连接。
  - “年轻”可以是自信、清楚、敢于行动，而不是幼态。
- 不照搬：香氛奢侈品的低信息密度、消费品牌广告语和汽车品牌的宏大叙事。

### 3.7 中国侧参考优先级

| 优先级 | 参考 | 在 Aijob 中负责 |
|---|---|---|
| 一级 | OPPO Design、flomo、少数派 | 整体中国气质、中文交互语气、阅读与任务节奏 |
| 二级 | HarmonyOS、TOPYS、不背单词 | 杂志式布局、编辑表达、低压力任务体验 |
| 三级 | 小宇宙、潮汐、观夏、蕉内、NIO Life | 人味、材质、色彩、品牌态度与情绪校准 |

一级参考可以进入组件和页面规则；二级参考进入版式与内容层级；三级参考只进入情绪板，不能直接决定交互。

## 5. Aijob 最终融合方向

### 5.1 一句话视觉北极星

> **骨架学 Figma 与 Tahatū，活力学 Wise 与 Monzo，中国气质学 OPPO Design 与 HarmonyOS，中文舒适度学 flomo 与少数派，编辑人味学 TOPYS 与小宇宙，东方留白学观夏与潮汐。**

这不是平均混合所有案例，而是明确三层关系：

1. **中文母语层**：页面先按中国学生的阅读、理解和决策习惯成立。
2. **国际方法层**：再用成熟产品的栅格、组件、动效和无障碍方法提升完成度。
3. **东方点睛层**：最后用少量色彩、材质、留白和边注建立辨识度。

如果去掉传统元素后页面就“不像中国”，说明中文排版和产品语气还没有真正做好；如果加上中国元素后像文创海报，说明点睛层过量。

### 5.2 情绪比例

R2 的视觉表现按以下比例控制：

- 45% 清晰可信：信息层级、证据、表单、表格和长文本。
- 25% 向阳活力：主色、标题、关键行动与阶段完成。
- 20% 编辑审美：留白、字体、图形构图和内容节奏。
- 10% 惊喜：空状态、微动效、局部插图和轻微非对称。

任何页面如果“惊喜”超过任务内容，就判定为过度设计。

### 5.3 视觉主题名称

内部设计方向暂命名为：

> **向阳生长 / Sunlit Momentum**

它不是自然植物主题，也不是校园青春插画，而是用光、方向、展开和连接表达“我正在向前”。

### 5.4 中国感的落地边界

采用：

- 米白纸感、墨色文字、群青主色、竹青生长色和朱橙提气。
- 功能无衬线为主，宋体/现代衬线只用于章节题、洞察导语与少量数字。
- 用“气口”控制留白，用“眉批/旁注”承载来源、未知和证据。
- 用笺页、折页、窗格、地平线和光束的几何抽象建立图形系统。
- 中文按钮优先使用明确动词：`看清条件`、`核对证据`、`做出决定`、`去官方投递`。

禁止：

- 红金组合、龙凤、灯笼、祥云、山水背景、满屏竹叶和水墨飞白。
- 在按钮、表单和数据区使用书法字体。
- 用仿印章红戳表示“官方”“可信”或“已通过”；当前来源状态必须按事实展示。
- 为了东方感牺牲可读性、对比度、键盘操作或响应式结构。

## 6. 设计系统建议

### 6.1 色彩：稳定底色上长出活力

建议先用以下角色定义 token，具体色值在 R2 首个页面切片中通过实际渲染再定：

| 角色 | 建议方向 | 使用范围 |
|---|---|---|
| `canvas` | 温润米白 / 轻纸色 | 页面背景和长时间阅读区 |
| `surface` | 清透白 | 表单、对照区和高密度工作区 |
| `ink` | 墨色近黑 | 正文、标题和主要边界 |
| `brand-primary` | 明亮群青 / 晴空蓝 | 主按钮、当前导航、关键路径 |
| `sun-accent` | 杏黄 / 日光橙 | 页面提气、阶段完成、小面积强调 |
| `growth-accent` | 竹青 / 清叶绿 | 已确认、已保存、向前推进 |
| `human-accent` | 朱橙 / 珊瑚红 | 欢迎、提示、人物与温度 |
| `muted` | 温和灰蓝 | 未知、未说明、次级信息 |

使用纪律：

1. 一个页面只允许一个品牌主色成为视觉主角。
2. 杏黄、竹青、朱橙只做 5%–12% 的局部提气。
3. 资格、证据、偏好仍靠文字、图标和结构区分，不能只靠颜色。
4. 朱橙不承担错误；错误和明确冲突使用独立、克制的深红。
5. 不使用全站彩虹渐变、荧光描边和大面积紫蓝渐变。
6. 不同时大面积使用红与金，避免节庆、礼盒和伪传统视觉。

### 6.2 字体：热情标题，安静正文

- 页面大标题使用有个性但不过度几何的展示无衬线；中文保持饱满、舒展和可读。
- 正文、表单和数据继续使用高可读功能无衬线。
- 允许在页眉引语、章节数字或洞察导语中使用少量现代宋体/精致衬线，制造中文编辑感。
- 标题不追求无条件巨大：
  - 页面主标题建议 48–64px。
  - 工作台标题建议 36–48px。
  - 正文保持 16–18px 和舒适行高。
- 不使用手写或书法字体模拟年轻，也不依赖英文才能成立。

### 6.3 图形语言：生长，而不是装饰

统一使用三类图形：

1. **展开形**：从一点展开的扇形、笺页、折页和路径，表达探索。
2. **连接形**：两到三个模块相遇、重叠或扣合，表达岗位与经历证据。
3. **向前形**：轻微上扬的线、地平线、方向块和光束，表达决定与下一步。

图形规则：

- 由简单几何形组成，轮廓清楚。
- 不使用随机贴纸、表情包、星星雨和装饰箭头。
- 不画“成功上岸”的虚假终点，也不制造能力升级动画。
- 与岗位事实无关的图形只出现在页头、空状态和阶段完成区域。
- 方形章记只能作为章节编号的几何母题，不能模拟公章、认证章或来源准入结论。

### 6.4 版式：洒脱来自空间，不来自混乱

- 1280 桌面端使用 12 列响应式网格。
- 页面首屏允许 7/5、8/4 等不完全对称构图，正文工作区回到稳定栅格。
- 减少整页同尺寸白卡；混合使用：
  - 开放式信息区。
  - 有色章节带。
  - 细边框工作区。
  - 少量重点卡片。
- 大留白集中在页头和阶段切换；岗位列表与简历工作台保持有效密度。
- 每个页面只设置一个主要视觉高潮，避免从头到尾都在强调。
- 岗位详情和洞察页保留 1–2 列边注带，让来源、日期、未知与核对提示像中文书刊眉批一样贴近对应事实。
- 边注在窄屏回到正文语义顺序，不能依靠绝对定位悬在页面外侧。

### 6.5 卡片与容器

- 圆角以 10–16px 为主，只有入口或阶段卡片可以更大。
- 默认使用细边框、色面和轻微层次，不依赖重阴影。
- 岗位卡从“独立白色 SaaS 卡片”改为更有编辑节奏的列表单元：
  - 左侧岗位与企业主信息。
  - 中部已知条件与未知项。
  - 右侧当前决定和明确下一步。
  - 小面积品牌色用于方向、更新时间或当前状态。
- 悬停只上移 1–2px 或改变边框/底色，不做 3D 翻转和大范围发光。

### 6.6 动效：让页面有呼吸，不让注意力被绑架

- 基础过渡 160–240ms，缓动自然。
- 允许的动效：
  - 页面区块轻微进入。
  - 章节像纸页轻轻展开，边注随对应事实出现。
  - 一束很短的光感移动提示下一步，不循环播放。
  - 筛选后列表平滑重排。
  - 保存决定时的短促确认。
  - 简历建议接受/撤销时的内容位移动画。
  - 三轴依据展开时的连线或高亮。
- 禁止：
  - 持续循环的背景动画。
  - 粒子、漂浮光球、跑马灯。
  - 战力增长、能力解锁和庆祝烟花。
  - 动画完成前无法操作。
- 支持 `prefers-reduced-motion`。

### 6.7 摄影与插图

- R2 不依赖企业照片，因为当前来源并不稳定提供这些素材。
- 如使用品牌氛围图，只使用少量真实、自然光、非摆拍的学生行动场景。
- 更推荐建立一组可复用的抽象品牌图形，而不是下载泛化职场图库。
- 空状态插图可以温暖、有幽默感，但不幼态、不卖惨、不制造成功承诺。

## 8. 不采用的“伪年轻化”与“伪中国化”

以下做法看起来年轻，但会降低 Aijob 的审美与可信度：

- 所有卡片都使用不同糖果色。
- 贴纸、emoji、手绘箭头和感叹号遍布工作台。
- 用大圆角、玻璃拟态和渐变代替信息设计。
- 每个页面都有超大营销标题。
- 匹配度环形图、雷达图、“战斗力 72”和升级动画。
- “优化后预计提升”或录用概率暗示。
- 无来源的性格适配、一天工作和隐含要求。
- 深色 AI 控制台、荧光线条、宇宙粒子。
- 用插画遮盖空数据、错误和未知。
- 红金配色、祥云边框、毛笔字、仿古卷轴和印章按钮。
- 把龙、凤、山水、窗棂或竹叶当作无处不在的背景装饰。
- 用“国潮”贴纸取代真正的中文排版、内容层级和交互语气。

## 9. 保留未来手机端能力

R2 暂不设计手机端专属导航、手势、底部 Tab 或移动端视觉细节，但必须保留：

1. 颜色、字号、间距、圆角、内容宽度和动效统一为设计 token。
2. CSS Grid/Flex 负责重排，不使用依赖桌面位置的绝对定位拼版。
3. 桌面双栏不改变语义阅读顺序，窄屏能自然堆叠。
4. 筛选、对照表和工具栏可折行、堆叠或局部滚动，不产生整页横向溢出。
5. 关键操作不依赖鼠标悬停。
6. 表单标签、焦点、错误和状态具有完整语义。
7. 320px 本轮只验收结构安全、核心短路径和内容不丢失，不做手机端专属精修。

## 11. coco 审核项

本轮只需审核以下六项：

1. 是否同意用“向阳、洒脱、聪明、可信”替代上一版偏冷静的视觉基调。
2. 是否同意“中国学生的母语体验优先，国际设计方法提高完成度，东方元素只做点睛”的融合顺序。
3. 是否同意以 OPPO Design + flomo + 少数派为中国侧一级参考，以 HarmonyOS + TOPYS + 不背单词为二级参考。
4. 是否同意“向阳生长 / Sunlit Momentum”作为 R2 暂定主题。
5. 是否同意米白底、群青主色、杏黄/竹青/朱橙局部提气，少量现代宋体和证据边注的视觉逻辑。
6. 是否同意明确排除红金、书法、祥云、仿印章等符号化中国风，以及贴纸、游戏化和满屏装饰。

审核通过后，R2 的下一步不是直接重写全站，而是：

1. 对现有七个页面制作 1280 截图与问题清单。
2. 建立第一版颜色、字体、空间、圆角、阴影和动效 token。
3. 先制作 `jobs` 页的高保真浏览器实现。
4. 用实际页面验证“有活力但不干扰”，再推广到其余页面。
