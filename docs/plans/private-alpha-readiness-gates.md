# Aijob Private Alpha 与上线就绪 Gate

- 状态：Active checklist / 非当前任务队列
- 生效日期：2026-08-09
- 当前任务入口：[路线图](../06-mvp-roadmap.md)与[当前交接](../handoffs/current.md)；本清单不安排开发顺序。

本文只定义进入真实参与者测试和推广上线前不能遗漏的条件。Gate 编号不表示当前开发顺序，也不得用于跳过路线图中的当前唯一目标。

## 1. 产品完整性 Gate

- M1–M4 全部通过，一岗闭环能在 AI 关闭时完成。
- Case、岗位版本、要求、证据、简历、投递、面试和复盘使用同一 owner 与业务真源。
- 旧 `/resume`、`/recommendations`、`/insights` 不再拥有第二套当前写入模型。
- 320px、200% 缩放和键盘流程可用；岗位首屏不加载简历编辑器或面试模块。

## 2. 数据与安全 Gate

- owner 对象鉴权、不可枚举 404、CSRF、`no-store`、幂等键和乐观修订冲突通过。
- 按 [ADR-0038](../decisions/0038-resume-workspace-and-direct-import.md)，保留原件、正文、经历和投递材料至用户主动删除，原件可下载；只有临时解析副本适用最长 24 小时清理。删除原件不删除正文，全部资料删除覆盖所有个人对象。新访客材料长期保留；旧匿名 owner 仅在仍活动且主动保存材料的事务中转换，不批量转换或复活过期/已删除数据，会话期限独立。
- 删除墓碑、迟到任务、备份恢复和版本回滚均不得复活已删除数据。
- 简历解析运行在非特权、无外网、资源受限的独立部署单元。
- 日志、告警和错误正文不包含简历、联系方式、密钥、提示词或完整模型输入。

## 3. Private Alpha 供给 Gate

- 供给单位按已接受的 ADR-0035 为在校生可投岗位；本硕博、实习、校招、应届和管培纳入；学历与院校条件不作全站排除，明确多年职业经验独立判断，未说明不推断补写。
- 100 家企业、1000 条可见活动岗位，日常缓冲 110 家、1100 条为必须如实呈现的报告项，不作为准入阻塞。原可达占比50%已撤销；单家公司无岗位上限（ADR-0036/0037），图谱同时报告岗位与企业分母。
- SME 两项比例降为观察指标，不再作为门槛（ADR-0032 替代 ADR-0027 该口径）。
- 用户可见岗位必须能探知关闭（来源列表型且消失即关闭，或岗位带明示截止日期）；`closure_detectable` 为 `eligible_for_alpha` 的必要条件。可见岗位「已截止但仍显示」不超过 7 天。
- 职能与城市分布均为观察指标，不再用原100/15/40条配额否决来源。
- 人工/浏览器来源企业20%、岗位10%的占比按ADR-0035作为报告项，不阻塞操作；不能省略实际分母与占比。
- 来源追溯率和未知诚实率 100%；关键字段、链接和新鲜度达到既定质量门。
- 至少 3 个已准入确定性 canonical 来源各累计成功刷新 ≥3 次且跨度 ≥3 天（ADR-0035：按观察次数与跨度计量，不依赖连续在线；机器关机只延后达标时间），失败隔离且无静默空结果、重复触网或目录污染。

## 4. 身份、服务器与运行 Gate

- Private Alpha 首选邮箱验证码；手机号短信仅在 coco 重新授权成本和供应商后评估。
- 私有 HTTPS 邀请入口、哈希凭证、Secure/HttpOnly Cookie 和持久化失败限流通过。
- 可重复镜像、迁移作业、最小数据库角色、配置校验、密钥引用、监控、回滚与备份恢复完成。
- 内部目标为 `RPO ≤24h`、`RTO ≤8h`。按 ADR-0037 记录硬件与数据分布，在 1 万岗位、50 并发混合请求下争取热目录/图谱 p95≤500ms、首个有用概览≤2秒；10 万岗位、100 并发只用于观察容量边界。分别报告冷/热/后台并行时延、全部失败和资源占用，累计尝试者不等于并发数。
- 云供应商、地区、预算和数据路径必须由 coco 明确授权；未授权不得部署真实用户环境。

## 5. AI 供应商 Gate

- Private Alpha 默认允许模板能力独立运行，AI 关闭不阻塞完整闭环。
- 按 ADR-0038，个人 AI 由用户配置 Chat Completions 兼容接口（包括兼容中转服务），不回退到运营方模型；用户启动任务后可使用其导入或填写的完整材料，不要求脱敏复核、逐句勾选或事实审批。Schema、来源引用、不编造事实及局部采用/撤销继续守门。
- 用户密钥按 owner 加密、不可读回、可撤销且不进入日志；任务与缓存受 owner/epoch、配置修订和个人预算约束。按 ADR-0043，搜索可选仅已有来源、复用经能力验证的个人 AI 或独立 Tavily，不强制两份 Key；配置兼容生成接口本身不证明具备搜索能力。
- 未形成供应商数据处理结论和增量价值证据前，远程环境不得默认启用 AI。

## 6. 用户验证与推广上线 Gate

- 不设固定人数的前置研究门槛；反馈随交付收集，首次面向 1000 人以内尝试者。
- 主体六阶段联验、来源准入、账号、运行环境、删除/恢复与故障演练通过后进入发布候选评审；不以增加候选功能无限延期。
- 供给规模和分布如实报告，不恢复 100/1000 或 10000 岗硬门槛；未经准入的来源不得公开。
