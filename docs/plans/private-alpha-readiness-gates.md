# Aijob Private Alpha 与上线就绪 Gate

- 状态：Active checklist / 非当前任务队列
- 生效日期：2026-08-09
- 当前执行路线：[Career OS 当前交付计划](career-os-current-delivery-plan.md)

本文只定义进入真实参与者测试和推广上线前不能遗漏的条件。Gate 编号不表示当前开发顺序，也不得用于跳过路线图中的当前唯一目标。

## 1. 产品完整性 Gate

- M1–M4 全部通过，一岗闭环能在 AI 关闭时完成。
- Case、岗位版本、要求、证据、简历、投递、面试和复盘使用同一 owner 与业务真源。
- 旧 `/resume`、`/recommendations`、`/insights` 不再拥有第二套当前写入模型。
- 320px、200% 缩放和键盘流程可用；岗位首屏不加载简历编辑器或面试模块。

## 2. 数据与安全 Gate

- owner 对象鉴权、不可枚举 404、CSRF、`no-store`、幂等键和乐观修订冲突通过。
- 原文件和临时解析最长 24 小时；职业资产长期保留并支持单项/全部删除。
- 删除墓碑、迟到任务、备份恢复和版本回滚均不得复活已删除数据。
- 简历解析运行在非特权、无外网、资源受限的独立部署单元。
- 日志、告警和错误正文不包含简历、联系方式、密钥、提示词或完整模型输入。

## 3. Private Alpha 供给 Gate

- 至少 100 家企业、1000 条可见活动可信实习岗位；日常缓冲为 110 家、1100 条。
- SME 企业不少于 50%，SME 岗位不少于 40%。
- 产品、运营、工程技术、数据与 AI 各至少 100 岗；其余既定职能各至少 15 岗。
- 北京、上海、深圳、广州、杭州、成都、武汉、南京各至少 40 条地点已知岗位。
- 人工/浏览器来源企业不高于 20%，岗位不高于 10%。
- 来源追溯率和未知诚实率 100%；关键字段、链接和新鲜度达到既定质量门。
- 至少 3 个已准入确定性 canonical 来源连续 7 天按 12 小时周期运行，失败隔离且无静默空结果、重复触网或目录污染。

## 4. 身份、服务器与运行 Gate

- Private Alpha 首选邮箱验证码；手机号短信仅在 coco 重新授权成本和供应商后评估。
- 私有 HTTPS 邀请入口、哈希凭证、Secure/HttpOnly Cookie 和持久化失败限流通过。
- 可重复镜像、迁移作业、最小数据库角色、配置校验、密钥引用、监控、回滚与备份恢复完成。
- 内部目标为 `RPO ≤24h`、`RTO ≤8h`；1000 岗和 20 个并发邀请会话下核心读取 p95 目标不高于 750ms、错误率低于 1%。
- 云供应商、地区、预算和数据路径必须由 coco 明确授权；未授权不得部署真实用户环境。

## 5. AI 供应商 Gate

- Private Alpha 默认允许模板能力独立运行，AI 关闭不阻塞完整闭环。
- 只支持通过白名单的国产模型供应商；平台内置 API 与用户自带 API 使用同一去标识化、Schema 校验和证据边界。
- 用户密钥必须加密、可撤销且不进入日志；中转站仅在后续明确政策允许时评估。
- 未形成供应商数据处理结论和增量价值证据前，远程环境不得默认启用 AI。

## 6. 用户验证与推广上线 Gate

- G0：2 人协议校准通过；实质修改任务或界面后重新校准。
- G1：6 人正式验证达到既定岗位发现、概念区分、决定质量和人工投递指标，且真实性、安全和隐私守护事件为 0。
- G4：产品、供给、服务器、G0/G1、来源持续性、删除/恢复和故障演练全部通过后，才能扩大 Private Alpha 邀请。
- 推广上线前可信可见岗位至少达到 10000 条，并至少覆盖产品、运营、技术、销售和 AI；具体分布门在真实扩容批次启动前由独立证据冻结。
